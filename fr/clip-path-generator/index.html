Générateur de clip-path — Formes CSS : polygone, cercle, ellipse et inset

En résumé : le Générateur de clip-path découpe n’importe quel élément en vraies formes — préréglages polygone (triangle, pentagone, hexagone, flèche, étoile), cercle, ellipse et inset arrondi — avec le CSS clip-path écrit pour vous.

clip-path est la façon dont les sites modernes découpent les images hero en angles et les photos en étoiles sans édition d’image. Choisissez une forme, voyez-la en direct, copiez une ligne.

Privé par conception : tout dans cet outil se passe à 100 % dans votre navigateur avec JavaScript. Vos données, photos et designs ne sont jamais téléversés sur un serveur, jamais stockés et jamais vus par nous - fermez l’onglet et tout a disparu.

Comment utiliser l’outil Générateur de clip-path

  1. Choisissez un type de forme ; pour les polygones, choisissez un préréglage.
  2. L’élément d’aperçu est découpé instantanément — le même code découpera vos propres images et sections.
  3. Copiez la déclaration clip-path.

Comment ça fonctionne

Les points des polygones sont des pourcentages de la boîte de l’élément, si bien que les formes se mettent à l’échelle avec l’élément. Contrairement aux astuces de bordures, clip-path découpe tout le rendu de l’élément — arrière-plans, images et bordures — et la partie découpée ne reçoit pas les clics.

Exemple travaillé

La photo hero d’une page d’accueil est découpée en hexagone pour correspondre à la géométrie du logo de la marque — aucun éditeur d’images, une ligne de CSS.

Questions fréquentes

Le clip-path fonctionne-t-il sur les images ?

Oui — il est surtout connu pour les images, mais il découpe n’importe quel élément, y compris des sections entières pour des séparateurs de page inclinés.

Puis-je faire un polygone personnalisé ?

Partez du préréglage le plus proche et ajustez les pourcentages dans le CSS copié — chaque paire est un point (x% y%), listé dans le sens horaire.

Le texte est-il aussi rogné ?

Le texte à l’intérieur de l’élément est découpé avec lui — pour les effets de texte, le Générateur de dégradés de texte est le meilleur outil.

Prise en charge par les navigateurs ?

Tous les navigateurs modernes prennent en charge les formes clip-path ; les formes polygon/circle/ellipse/inset utilisées ici sont l’ensemble le plus sûr.
