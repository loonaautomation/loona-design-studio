家譜製作工具 — 免費三代家譜樹

簡言之： 家譜製作工具佈局三代——父母在上，主要人物和伴侶在中間，孩子在下——帶乾淨的連線線，從您簡單輸入的姓名。

學校專案、家庭聚會、給祖父母的禮物：一棵整潔的家譜大部分是打字，如果佈局自己完成的話。填入姓名，世代會自行排列。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用家譜製作工具

  1. 在頂行輸入父親和母親的名字。
  2. 在中間行輸入主要人物和他們的伴侶。
  3. 列出孩子，每行一個——任意數量；底行會自動伸展和居中。
  4. 下載 PNG 用於印刷或分享。

工作原理

位置按代計算：父母和中間夫婦坐落在頁面中央，父母的垂線落在主要人物身上，孩子們均勻分佈在底行，與夫婦共用一條橫杆——標準的家譜佈局，只從您的姓名計算。

例項

在學校專案中，一名學生透過父母輸入祖父母一代，在下方新增自己、哥哥和妹妹——然後列印出一棵樹，老師把它釘在板上。

常見問題

我可以新增祖父母或孫輩嗎？

這個製作工具涵蓋三代（父母、夫婦、孩子）。對於更大的樹，每代製作一張圖並把它們放在一起——一張的主要人物成為下一張的孩子。

如果沒有伴侶怎麼辦？

把伴侶框留為“—”或稍後輸入名字；佈局仍然有效。

能放下多少孩子？

該行適合任何數量並把孩子居中；非常大的家庭會得到小方框，因此每圖 8 個或更少讀起來最好。

名字會被儲存在任何地方嗎？

不——名字只存在於您的瀏覽器標籤頁中。
