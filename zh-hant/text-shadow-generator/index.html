文字陰影生成器 — 帶實時預覽的 CSS 文字效果

簡言之： 文字陰影生成器實時設計 CSS text-shadow——偏移光源、用模糊柔化、選擇任何陰影顏色——並匯出單個宣告。

一絲陰影把標題從繁忙的背景中托起；硬偏移讓復古字型跳出來。這個工具讓您在真實標題字號下先看清兩種效果再做決定。

如何使用文字陰影生成器

  1. 輸入您的標題，像真實的那樣設定大小。
  2. 拖動陰影：右下讀作光線來自左上（自然的預設）。
  3. 複製 text-shadow 宣告。

工作原理

text-shadow 接受 offset-x、offset-y、blur 和 colour——沒有 spread（與 box-shadow 不同）。blur 為 0 時給出硬朗的復古偏移；提高它會把陰影融化成輝光，尤其是在深色背景上配明亮顏色時（如預覽中）。

例項

藍綠色上的白色海報標題加上金色 3px 偏移陰影——突然看起來像印刷品，而不是打出來的字。

常見問題

文字陰影與盒陰影的區別？

盒陰影跟隨元素的矩形；文字陰影跟隨字形本身。標題需要文字陰影。

如何製作輝光？

把偏移設為 0，提高模糊，在深色背景上使用明亮的顏色。

我可以疊加陰影嗎？

是的——在 CSS 中用逗號分隔重複該值模式，用於輪廓和 3D 堆疊。

它損害可讀性嗎？

保持陰影在閱讀文字時微妙；只為展示標題用大膽陰影。
