思維導圖製作工具 — 免費線上思維導圖，帶自動佈局

簡言之： 思維導圖製作工具從一箇中心想法生長出整潔的圖：點選任何節點，用按鈕或鍵盤新增子節點和同級節點，樹會自動重新佈局——然後匯出 PNG 或把地圖儲存為 JSON 以便以後繼續。

課程規劃、作文結構、專案分解、複習筆記——思維導圖把糾纏的話題變成一幅圖。把大想法放在中間，向外分支；工具在您思考時保持一切整潔。

點選一個節點選中它。拖動空白處平移。每次更改後佈局會自動整理。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用思維導圖製作工具

  1. 點選中心節點，在所選節點文字框中輸入您的主要想法。
  2. 按新增子節點（或 Tab 鍵）從所選節點分支；按新增同級節點（或 Enter）在同一級別得到一個節點。
  3. 點選任何節點編輯其文字。拖動空白處平移，使用縮放或適應來框住整個圖。
  4. 下載 PNG 分享或列印，或另存為 JSON 以後載入回來繼續編輯。

工作原理

地圖是節點的樹。一個整潔的佈局演算法測量每個分支：一個分支與其孩子以均勻間距堆疊一樣高，父母位於其孩子旁邊居中，每級有自己的列——因此無論樹如何生長，方框永不重疊。邊緣繪製為平滑曲線。匯出把相同的佈局渲染到一張按地圖精確大小的新畫布上，JSON 儲存/載入把整棵樹儲存為您可以儲存在任何地方的純文字。

例項

一位規劃科學單元的老師以“水迴圈”為中心，新增子節點蒸發、凝結、降水和彙集，再為每個子節點新增兩個細節節點。完成的 PNG 成為課堂講義，JSON 檔案讓她下學期能擴充套件同一張圖。

常見問題

如何快速新增節點？

選擇一個節點，按 Tab 得子節點或 Enter 得同級節點。畫布上方的按鈕在觸控式螢幕上做同樣的事。

我可以儲存思維導圖以後繼續嗎？

是的——另存為 JSON 下載整個地圖。使用載入選擇器再次開啟它並繼續編輯。

大地圖會保持可讀嗎？

佈局從不重疊方框，您可以平移、縮放和使用適合檢視檢視一切。PNG 匯出按完整地圖定尺寸，因此什麼都不會被切掉。

我的思維導圖私密嗎？

完全私密——圖只存在於您的瀏覽器中。我們不會上傳或儲存任何內容。

我可以改變顏色嗎？

是的——五種主題（青色與金色、海洋、日落、葡萄和單色）即時重塑整個地圖。
