詞雲生成器 — 從您的文字免費生成詞雲

簡言之： 詞雲生成器統計您文字中的詞，並把最頻繁的那些繪製得最大——一幅即時的視覺摘要，說明一份檔案真正講的是什麼。

演講、散文、評論、整整一章：詞雲一眼展示一文的詞彙，併為教室和演示製作引人注目的海報。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用詞雲生成器

  1. 把文字貼上到框中——輸入時詞雲就會構建。
  2. 常見小詞（the、and、of……）預設會被移除，讓真正的內容詞佔主導；勾選方框可保留它們。
  3. 選擇要包含的詞數和背景顏色。
  4. 下載 PNG 用於您的幻燈片、海報或教室牆面。

工作原理

頻率被精確計數（不區分大小寫，去標點）。字型大小隨頻率的平方根增長——讓一個巨詞不壓垮其餘詞的標準加權。詞從中心向外沿擴充套件螺旋放置，每個詞都與每個已放置的詞檢查，因此沒有重疊；放不進畫布的詞會被誠實跳過，計數會報告在畫布下方。

例項

一位老師貼上她即將講授的章節。詞雲中“river”高高聳立——課程的匯入已經自己寫好了。

常見問題

詞的大小如何決定？

按頻率，並按平方根縮放：使用頻率 4 倍的詞會出現 2 倍高——易讀，又不會讓頂部詞主導一切。

什麼是停用詞？

每個文字中出現的微小語法詞（the、and、is……）。移除它們（預設）讓有意義的詞顯現。

為什麼一個詞不見了？

無法在不重疊的情況下放下的詞會被跳過——少提高詞限，或縮短文字。狀態行總是報告放置了多少。

我的文字會被上傳嗎？

從不——計數和繪製在您的瀏覽器中進行。
