圖片標註編輯器 — 為截圖新增箭頭、標籤與隱私模糊

簡言之： 圖片標註編輯器按教程和錯誤報告需要的方式標記截圖和圖片：粗箭頭、高亮框、文字標籤——以及在分享前畫素化姓名、數字或面孔的隱私模糊。匯出按圖片的完整原始解析度渲染。

這不是照片編輯器——這裡沒有濾鏡或美化工具（Loona Image Tools 負責照片編輯）。這個工具只有一個工作：解釋和保護。指向按鈕，標註步驟，模糊賬號編號，分享一張教人而不暴露的截圖。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用圖片標註編輯器

  1. 上傳您想解釋的截圖或圖片。它只載入到您的瀏覽器中。
  2. 選擇箭頭，從眼睛應該開始的地方拖到您所指的東西。用方框來框住一個區域，用文字標籤（先輸入文字，再點選放置）。
  3. 選擇隱私模糊，拖過任何敏感內容——姓名、電話號碼、賬戶詳情、人臉。該區域會被畫素化，無法閱讀。
  4. 撤銷移除最後一個標記。下載匯出帶每個標記的全解析度 PNG。

工作原理

標記儲存為相對於顯示圖片的座標，然後在匯出時按圖片的自然解析度重新渲染——因此箭頭和標籤即使在大截圖上也保持清晰。模糊會取樣原始圖片區域，把它縮小到幾個畫素再在關閉平滑的情況下拉回來，這摧毀了細節而不是僅僅遮住它。一切都在本地執行；圖片從不離開您的裝置。

例項

在準備操作指南時，一位老師給學校門戶截圖，畫一個紅色箭頭指向“提交”按鈕，標註為“1 — 點選提交”，把學生 ID 列模糊，並匯出一張可以安全發給每位家長的指南圖片。

常見問題

這與 Loona Image Tools 有何不同？

Image Tools 編輯照片——調整大小、壓縮、濾鏡、水印。這個編輯器為截圖做標註以便說明：箭頭、方框、標籤和隱私模糊。不同的工作，不同的工具。

模糊真的能隱藏資訊嗎？

是的——該區域以粗塊大小從原始畫素畫素化，因此底層文字或面孔在匯出時被摧毀，而不只是被覆蓋。分享前始終檢查匯出的圖片。

匯出會模糊嗎？

不——標記按圖片的完整原始解析度重新渲染，因此匯出與源截圖一樣清晰。

放置標記後我可以移動它嗎？

使用撤銷移除最後一個標記並重新放置它——標記按順序保留，因此撤銷一次回退一步。

我的截圖會被上傳到任何地方嗎？

從不。圖片及其標記只存在於您的瀏覽器中。
