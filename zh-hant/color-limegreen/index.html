Limegreen — #32CD32

簡言之： Limegreen 是 #32CD32（RGB 50, 205, 50）——一種暖中性、中間色調的綠色顏色，附完整的計算檔案、色階與和諧色。

用好 Limegreen

Limegreen 屬於綠色色系，明度為 50%——一種中間色調、中度飽和、暖中性的顏色。作為背景，它與黑色文字搭配最好（對比度 9.91:1）。其互補色（#CD32CD）是行動號召和高亮的高能量夥伴；類似色鄰居（#80CD32、#32CD80）給出平靜的同色系漸變。印刷時，從上面的 CMYK 值開始並校樣——螢幕上的 Limegreen 是 sRGB 顏色，濃郁的螢幕色調在印刷時可能發生偏移。

常見問題

Limegreen 的十六進位制程式碼是什麼？

#32CD32 —— CSS 命名顏色“limegreen”。其 RGB 為 (50, 205, 50)。

Limegreen 適合用作文字還是背景？

作為背景，黑色文字在它上面讀起來最好（9.91:1）。作為文字本身，在白色上它達到 2.12:1——對 AA 級正文文字不夠；請把它用於標題、大文字或強調。

什麼顏色與 Limegreen 相配？

其互補色 #CD32CD 用於對比，類似色 #80CD32 和 #32CD80 用於平靜的組合，以及上面的 50–950 色階用於單色設計。

Limegreen 的印刷 CMYK 是多少？

C76 M0 Y76 K20。螢幕顏色的 CMYK 轉換是一個起點——印刷前始終先校樣再批次印刷。
