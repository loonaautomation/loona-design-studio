箱線圖製作工具 — 免費箱須圖

簡言之： 箱線圖製作工具從每個系列的原始值計算五數摘要——最小值、第一四分位數、中位數、第三四分位數、最大值——併為每個組繪製真正的箱須圖。

平均值會掩蓋分佈。箱線圖展示中位數、中間一半數值的所在位置，以及極端值延伸到多遠——這是比較組別最誠實的方式。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用箱線圖製作工具

  1. 把每個組的原始數值輸入為一個系列——每行一個值（行只是槽位；更大的組新增更多行）。
  2. 製作工具逐系列計算四分位數，每個組繪製一個箱體。
  3. 比較中位數和分佈，然後下載 PNG。

工作原理

四分位數對排序後的值使用線性插值（電子表格使用的標準 type-7 方法）。箱體跨越 Q1 到 Q3，裡面的線是中位數，須線到達最小值和最大值。圖表由 Loona 的共享圖表引擎在 HTML 畫布上手工繪製——沒有圖表庫，也沒有伺服器。一切都在本地計算，因此您的數字永遠不會離開您的裝置。

常見問題

箱體各部分的含義是什麼？

箱體覆蓋中間 50% 的值（Q1 到 Q3）。裡面的線是中位數。須線到達最小和最大值。

四分位數如何計算？

對排序資料做線性插值——與電子表格的 QUARTILE 函式相同的方法。

每組多少個數值？

至少四個才能得到有意義的箱線圖；八個或更多更好。所有組應有相同的行數——只有在您理解其影響時，才用重複中位數來補齊較短的組；更好的做法是收集相等的樣本。

我的資料私密嗎？

是的——完全在您的瀏覽器中計算。
