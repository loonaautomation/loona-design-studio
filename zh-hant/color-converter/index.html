顏色轉換器 — HEX、RGB、HSL、HSV 與 CMYK（擴充套件版）

簡言之： 顏色轉換器一次顯示一種顏色的每種主要表示法——HEX、RGB、HSL、HSV/HSB 和 CMYK——加上相對亮度和它對黑色和白色的對比度。

設計師用 HEX 思考，印刷商要 CMYK，CSS 要 HSL，無障礙按對比度評判。這個擴充套件轉換器把它們全放在一個螢幕上，讓工具之間不丟失任何東西。

如何使用顏色轉換器

  1. 輸入一個 HEX 顏色或使用選擇器。
  2. 閱讀網格中的每個表示法——每個都由同一種顏色計算，因此它們總是相符。
  3. 複製整個塊，或只複製您需要的那一行。

工作原理

轉換使用標準的色彩空間數學：HSL/HSV 由歸一化 RGB 得出，CMYK 用通常的 K 提取公式，WCAG 相對亮度（帶 gamma 校正）用於對比度——與無障礙檢查器報告的數字相同。

例項

一位開發者從設計師那裡收到 HEX 格式的品牌色，需要給印刷商的 CMYK 和給 CSS 懸停狀態的 HSL——在這裡貼上一次就能得到全部三個答案，還附帶對比度檢查。

常見問題

哪種格式是“正確的”？

它們描述的都是同一種顏色。HEX/RGB 用於螢幕，HSL 用於設計調整，CMYK 用於印刷，HSV 用於取色器。

什麼是好的對比度？

WCAG 要求普通文字對背景至少 4.5:1。在網格中用白色和黑色檢查您的文字顏色。

這裡的 CMYK 與我的印表機完全匹配嗎？

它是標準的數學轉換——一個有力的起點。專業印刷在最終校樣時使用 ICC 配置檔案。

我可以輸入 RGB 來代替嗎？

使用顏色選擇器，它覆蓋整個 RGB 空間，或使用色階工具的選擇器——HEX 在各處更新。
