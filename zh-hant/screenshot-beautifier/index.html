截圖美化工具 — 把截圖變成可分享的圖片

簡言之： 截圖美化工具把您的截圖放在豐富的漸變背景上，頻寬裕的內邊距、圓角、柔和陰影和淺色畫框邊緣——產品頁面和社交帖子上看到的精美外觀——並匯出為一張 PNG。

原始截圖在資訊流裡顯得平淡；同一張截圖漂浮在漸變上、留有呼吸空間，看起來就像產品釋出。從剪貼簿直接貼上截圖（Ctrl+V），調整內邊距，下載一張能贏得注意的圖片。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用截圖美化工具

  1. 上傳一張截圖——或乾脆複製一張，在本頁任何地方按 Ctrl+V 貼上它。
  2. 選擇一個漸變背景（點按一個色卡）——青金色、日落、海洋、葡萄、玫瑰、巖板、沙色或森林。
  3. 調整截圖周圍的內邊距及其圓角；切換柔和陰影和畫框邊緣。
  4. 按下載美化 PNG，在任何地方分享它。

工作原理

輸出畫布從截圖自身的大小加上您在每邊的內邊距計算，因此截圖本身從不被裁剪或拉伸——大截圖擬合到長邊最多 1400 畫素，以保持匯出快速。漸變對角繪製，截圖被裁剪為圓角矩形，陰影在圖片繪製之前由畫布陰影引擎渲染。貼上在瀏覽器內直接從您的剪貼簿讀取圖片。

例項

一位老師擷取她的線上測驗結果頁面，貼上到這裡，選擇寬內邊距的 Ocean 漸變，下載一張可直接釋出的圖片發到學校頁面——沒有學生姓名可見，結果看起來像公告，而不是截圖。

常見問題

如何貼上截圖？

把截圖複製到剪貼簿（例如用截圖工具或 Print Screen），開啟本頁並按 Ctrl+V。圖片會立即出現——不需要檔案。

我的截圖會被上傳嗎？

不。貼上和上傳都只是把圖片載入到您的瀏覽器中；美化後的 PNG 在您的裝置上建立。

我的截圖會被調整大小嗎？

只有在它非常大時：截圖會被擬合到長邊最多 1400 畫素，以保持匯出快速。比例從不改變。

我可以用純色背景代替漸變嗎？

選擇沙色漸變得到近純色的淺色背景，或選擇巖板選項得到近純色的深色背景。

結果可以用於什麼？

社交帖子、部落格頁首、應用商店風格預覽、教程和演示——任何截圖需要看起來設計過的地方。
