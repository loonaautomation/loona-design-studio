語錄圖製作工具 — 免費社交媒體語錄圖片

簡言之： 語錄圖製作工具把您的文字放在照片或豐富的顏色背景上，以社交資訊流喜愛的三種尺寸——正方形、縱向和故事——帶居中字型和署名行。

純文字帖子一滑而過；同樣的文字做成設計圖片就會被儲存和分享。新增背景照片，輸入引言，然後下載。

點選一個塊選中它，拖動移動，拖動其右下角調整大小。圖層：使用後移一層/前移一層。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用語錄圖製作工具

  1. 選擇尺寸和入門模板——每個模板完全可編輯，沒有任何東西被鎖定。
  2. 點選任何文字、形狀或照片塊進行編輯：拖動移動，拖動角調整大小，在畫布下方的編輯器中重新設定樣式。
  3. 新增您自己的照片塊和背景，用後移一層/前移一層排列圖層。
  4. 按您選擇的精確尺寸下載 PNG，或用列印/另存為 PDF 製作紙質副本。

工作原理

照片模板中的深色帶是一個簡單實現的半透明技巧：文字後面一塊純深青色塊讓它們在任何照片上都可讀——隨意移動或刪除它。對於照片背景，使用頂部的背景圖片選擇器。本頁執行在 Loona 的共享畫布編輯器上：您的設計是由文字、形狀和照片塊組成的堆疊，按所選的精確畫素尺寸渲染，因此匯出結果可直接用於印刷和平台。塊被限制在畫布內，圖層可以重新排序。一切都在您的瀏覽器中完成——照片從不上傳。

例項

一個學校頁面每週一從 Clean Colour 模板釋出一句語錄——同樣的版式、新的文字——家長們開始儲存它們了。

常見問題

什麼尺寸效果最好？

正方形用於資訊流，縱向用於更多資訊流空間，故事用於全屏故事和狀態。

如何把文字放在繁忙的照片上？

讓文字後面的深色帶塊保持在原處（把文字移到前面），或選擇一張更平靜的照片。可讀性就是設計。

我可以用我自己的照片嗎？

是的——背景圖片或照片塊，直接從您的裝置。

它免費嗎？

是的——免費，沒有註冊，沒有水印。
