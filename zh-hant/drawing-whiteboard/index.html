繪畫白板 — 帶形狀與撤銷的免費線上素描板

簡言之： 繪畫白板是您瀏覽器中的即時素描板：手繪筆、橡皮、線條、矩形和圓形工具，任何顏色和筆刷大小，撤銷和重做——以及您的畫板 PNG 下載。

解釋一個想法、勾勒一個佈局、在螢幕上解一道題，或讓學生畫畫——白板是大聲思考最快的方式。開啟頁面畫畫；沒有什麼要安裝，也沒有什麼要儲存到伺服器。

按設計私密： 這個工具中的一切 100% 在您的瀏覽器中使用 JavaScript 進行。您的資料、照片和設計從不上傳到伺服器，從不儲存，也從不被我們看到——關閉標籤頁，一切都消失。

如何使用繪畫白板

  1. 選擇一個工具：筆用於手繪，橡皮用於擦除，或線條、矩形和圓形用於乾淨的形狀。
  2. 選擇顏色和畫筆粗細。用滑鼠、手指或觸控筆繪畫——拖動時形狀會實時預覽。
  3. 出錯了？撤銷一次回退一筆，重做把它帶回來，清除清空畫板。
  4. 按下載白板 PNG 來儲存或分享完成的素描。

工作原理

每一筆和每個形狀都儲存為資料——工具、顏色、大小和點——畫板從該列表重繪，這正是精確撤銷和重做成為可能的原因。形狀從您的拖動（起始角到結束角）歸一化，因此您可以向任何方向拖動。指標和觸控事件一起處理，因此同一套程式碼適用於課堂上的滑鼠或手機上的手指。

例項

在線上課程中，一位老師實時勾勒水迴圈——太陽、箭頭、雲朵圓圈和標籤——撤銷一支歪箭頭，重畫它，然後下載 PNG 作為複習筆記發到班級群。

常見問題

白板在手機或平板上能用嗎？

是的——它使用觸控友好的指標事件，因此手指和手寫筆繪圖與滑鼠一起工作。

橡皮的作用是什麼？

橡皮用畫板的白色背景顏色塗抹，擦除其筆劃下面的任何東西。撤銷恢復任何誤刪的東西。

我可以撤銷多少步？

每一筆和每個形狀都是一個撤銷步驟，標籤頁開啟時整個畫板歷史都會保留。

有任何東西被上傳嗎？

不。畫板及其歷史只存在於您的瀏覽器記憶體中。

下載的圖片尺寸是多少？

畫板以其完整的 1060 × 620 畫素畫布大小匯出為 PNG。
