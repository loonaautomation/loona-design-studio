三次貝塞爾緩動生成器 — 視覺化 CSS 動畫曲線

簡言之： 三次貝塞爾曲線生成器讓您塑造 CSS 緩動曲線——每個過渡和動畫的加速感——帶四個控制點、著名預設、繪製的曲線，以及一個回放您確切緩動的球。

ease、ease-in 和 ease-out 只是運動感覺的無限空間中的三個點。這個工具開啟整個空間：拖動曲線，直到球以您的介面應該感覺的方式運動。

如何使用三次貝塞爾曲線生成器

  1. 從預設開始學習地標（ease、back、bounce-out）。
  2. 調整手柄：手柄 1 決定動作的開始，手柄 2 決定結束。超出 0–1 的 Y 值會產生過沖（預備和回彈）。
  3. 把 cubic-bezier() 值複製到您的 transition 或 animation 中。

工作原理

CSS 三次貝塞爾曲線是一條從 (0,0) 到 (1,1)、帶有兩個控制點的引數曲線。瀏覽器的求解方式與本頁完全相同：給定時間 x，找到 x 與之匹配的曲線引數（這裡用二分查詢），再讀取其 y 作為進度。超出範圍來自 y 值在 [0,1] 之外的控制點。

常見問題

四個數字的含義是什麼？

兩個控制點：（x1, y1, x2, y2）。x 是時間（必須保持在 0–1）；y 是進度（可自由超調）。

為什麼球在“back”時向後走？

負的 y1 會讓進度先降到零以下——投擲前的蓄勢。正是這種預備動作讓動效有了生命力。

UI 緩動——好的預設嗎？

ease-out 曲線（快速開始，輕柔著陸）適合大多數介面運動；ease-in 適合離開螢幕的元素。

我的曲線是有效的 CSS 嗎？

是的——任何 [0,1] 中的 x 都有效；生成器的滑塊精確地執行這一點。
