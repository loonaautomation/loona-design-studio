Seagreen — #2E8B57

用好 Seagreen

Seagreen 屬於綠色色系，明度為 36%——一種中間色調、中度飽和、暖中性的顏色。作為背景，它與黑色文字搭配最好（對比度 4.95:1）。其互補色（#8B2E62）是行動號召和高亮的高能量夥伴；類似色鄰居（#348B2E、#2E8B86）給出平靜的同色系漸變。印刷時，從上面的 CMYK 值開始並校樣——螢幕上的 Seagreen 是 sRGB 顏色，濃郁的螢幕色調在印刷時可能發生偏移。

常見問題

Seagreen 的十六進位制程式碼是什麼？

#2E8B57 —— CSS 命名顏色“seagreen”。其 RGB 為 (46, 139, 87)。

Seagreen 適合用作文字還是背景？

作為背景，黑色文字在它上面讀起來最好（4.95:1）。作為文字本身，在白色上它達到 4.25:1——對 AA 級正文文字不夠；請把它用於標題、大文字或強調。

什麼顏色與 Seagreen 相配？

其互補色 #8B2E62 用於對比，類似色 #348B2E 和 #2E8B86 用於平靜的組合，以及上面的 50–950 色階用於單色設計。

Seagreen 的印刷 CMYK 是多少？

C67 M0 Y37 K45。螢幕顏色的 CMYK 轉換是一個起點——印刷前始終先校樣再批次印刷。
