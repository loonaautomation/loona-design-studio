Beige — #F5F5DC

簡言之： Beige 是 #F5F5DC（RGB 245, 245, 220）——一種暖、淺的黃色顏色，附完整的計算檔案、色階與和諧色。

CSS 定義的 148 種命名顏色之一——本頁是它完整的工作檔案：每種格式、WCAG 對比度、50–950 色階和計算出的和諧色，全部可直接複製。

用好 Beige

Beige 屬於黃色色系，明度為 91%——一種淺、中度飽和、暖的顏色。作為背景，它與黑色文字搭配最好（對比度 18.98:1）。其互補色（#DCDCF5）是行動號召和高亮的高能量夥伴；類似色鄰居（#F5E9DC、#E9F5DC）給出平靜的同色系漸變。印刷時，從上面的 CMYK 值開始並校樣——螢幕上的 Beige 是 sRGB 顏色，濃郁的螢幕色調在印刷時可能發生偏移。

常見問題

Beige 的十六進位制程式碼是什麼？

#F5F5DC —— CSS 命名顏色“beige”。其 RGB 為 (245, 245, 220)。

Beige 適合用作文字還是背景？

作為背景，黑色文字在它上面讀起來最好（18.98:1）。作為文字本身，在白色上它達到 1.11:1——對 AA 級正文文字不夠；請把它用於標題、大文字或強調。

什麼顏色與 Beige 相配？

其互補色 #DCDCF5 用於對比，類似色 #F5E9DC 和 #E9F5DC 用於平靜的組合，以及上面的 50–950 色階用於單色設計。

Beige 的印刷 CMYK 是多少？

C0 M0 Y10 K4。螢幕顏色的 CMYK 轉換是一個起點——印刷前始終先校樣再批次印刷。
