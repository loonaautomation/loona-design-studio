CSS 載入動畫生成器 — 圓環、弧形與圓點（純 CSS）

簡言之： CSS 載入動畫生成器構建純 CSS 載入動畫——經典圓環、遮罩錐形圓弧或彈跳圓點——帶大小、粗細、顏色和速度控制，並匯出包括 keyframes 的完整 CSS。

每個應用都需要載入狀態，而 GIF 載入器又重又模糊。這三個載入器每個只需幾行 CSS：輕量、任何尺寸都清晰、改一個值就能重新著色。

如何使用CSS 載入動畫生成器

  1. 選擇樣式：圓環經典，弧形現代極簡，圓點友好。
  2. 設定大小、粗細、顏色和速度——預覽執行真實動畫。
  3. 複製 CSS。對於圓點樣式，HTML 片段已作為註釋包含在輸出中。

工作原理

圓環和圓弧載入動畫用 keyframes 動畫旋轉整圈；圓弧使用被遮罩成圓環的 conic-gradient，使其尾部幾何地淡出。圓點在一次彈跳 keyframe 上使用交錯的動畫延遲——延遲，而不是單獨的動畫，創造了波浪。

常見問題

哪個載入動畫最專業？

中等速度（0.8–1 秒）的圓環是企業標準。圓點感覺更友好；圓弧感覺最現代。

它會尊重減少動態效果的設定嗎？

在 CSS 中新增媒體查詢：@media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } }——減慢而不是移除，能保留含義。

我以後可以改變速度嗎？

是的——複製的 CSS 中的一個數字（動畫時長）。

純 CSS——沒有 JavaScript？

正確。預覽使用工具匯出的同一套 CSS。
