證書製作工具 — 免費可列印證書，單張或批次製作

簡而言之：證書製作工具可建立可直接列印的 A4 橫向證書 — 選擇範本、輸入姓名、列印即可。需要為整個班級或整期課程製作？貼上 CSV 名單，它會自動為每個人產生一張證書。

學校、學院、培訓中心和小型團隊每週都要頒發證書，通常使用的工具速度慢、一次只能做一張。這款製作工具能勝任兩種工作：一分鐘內做出一張精美的證書，或從試算表批次產生整批證書 — 姓名、課程和日期都會為您自動填好。

請貼上包含 name、course、date 三欄的 CSV 內容（標題列可省略），或上傳 .csv 檔案。表單中的範本、樣式、說明文字、頒發機構和簽署人將用於每一張證書。

注重隱私的設計：此工具中的一切操作 100% 透過 JavaScript 在您的瀏覽器中完成。您的姓名、班級名單和設計絕不會上傳到伺服器，絕不會被儲存，我們也絕不會看到 — 關閉分頁後，一切都會消失。

如何使用證書製作工具

  1. 選擇範本和樣式，然後輸入獲獎者姓名、課程或活動名稱、日期、頒發機構和簽署人。預覽會隨著您的輸入即時更新。
  2. 如需單張證書，請點按「下載 PNG」取得高解析度圖片，或點按「列印 / 另存為 PDF」取得清晰的 A4 橫向頁面。
  3. 如需批次製作，請切換到「透過 CSV 批次產生」，貼上您的名單（name, course, date）或上傳 .csv 檔案，然後點按「產生證書」。
  4. 在批次結果中逐張瀏覽以下載單張 PNG，或選擇「列印全部證書」，按每頁一張的方式列印。

運作原理

每張證書都以精確的 A4 橫向比例（297 × 210 毫米）繪製為向量設計，因此文字在任何列印尺寸下都保持清晰。在批次模式下，製作工具會在本機讀取您的 CSV 列，將同一設計逐人填入，並準備好每頁一張證書的列印版面。較長的姓名會自動適配設計。任何內容都不會上傳 — 即使有數百個姓名，整批證書也全部在您的裝置上產生。

完整範例

一位老師為 28 名學生完成了為期兩週的電腦課程。她將班級名單匯出為 CSV，貼到批次模式中，選擇 Classic 金色，然後一次列印全部 28 張證書 — 每張都帶有學生姓名、課程名稱和相同日期 — 用時比過去製作一張證書還要短。

常見問題

批次模式需要什麼 CSV 格式？

三欄：name、course、date — 按此順序排列。帶有這些名稱的標題列可省略。包含逗號的欄位可以用雙引號括起來，與試算表應用程式匯出的格式完全一致。

可以加入真實簽名嗎？

輸入簽署人姓名後，姓名會以優雅的手寫體樣式繪製在簽名線上方。如需手寫簽名，請列印證書後親手簽署 — 大多數學校和學院都更喜歡這種方式。

證書以什麼尺寸列印？

A4 橫向（297 × 210 毫米），每頁一張證書。PNG 下載尺寸為 3369 × 2382 像素，清晰度足以滿足專業列印需求。

我的班級名單是私密的嗎？

可以 — CSV 在您的瀏覽器內讀取，絕不會上傳。姓名和名單始終保留在您的裝置上。
