用好 Light Slate Gray

Light Slate Gray 屬於藍色色系，明度為 53%——一種中間色調、柔和、涼的顏色。作為背景，它與黑色文字搭配最好（對比度 5.77:1）。其互補色（#998877）是行動號召和高亮的高能量夥伴；類似色鄰居（#779999、#777799）給出平靜的同色系漸變。印刷時，從上面的 CMYK 值開始並校樣——螢幕上的 Light Slate Gray 是 sRGB 顏色，濃郁的螢幕色調在印刷時可能發生偏移。

常見問題

Light Slate Gray 的十六進位制程式碼是什麼？

#778899 —— CSS 命名顏色“lightslategray”。其 RGB 為 (119, 136, 153)。

Light Slate Gray 適合用作文字還是背景？

作為背景，黑色文字在它上面讀起來最好（5.77:1）。作為文字本身，在白色上它達到 3.64:1——對 AA 級正文文字不夠；請把它用於標題、大文字或強調。

什麼顏色與 Light Slate Gray 相配？

其互補色 #998877 用於對比，類似色 #779999 和 #777799 用於平靜的組合，以及上面的 50–950 色階用於單色設計。

Light Slate Gray 的印刷 CMYK 是多少？

C22 M11 Y0 K40。螢幕顏色的 CMYK 轉換是一個起點——印刷前始終先校樣再批次印刷。
