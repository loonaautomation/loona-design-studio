フローチャートメーカー — スマートコネクタ付きの無料フローチャート

要するに： フローチャートメーカーは五つの標準図形からきれいなフローチャートを構築します — 開始／終了、処理、判断、入出力、文書 — YesやNoのような任意のラベル付き自動エルボーコネクタで結ばれ、完成したチャートをPNGとしてエクスポートします。

プロセス、アルゴリズム、入学手続き、トラブルシューティングガイド — フローチャートはステップの順序を誤解不可能にします。図形を追加し、位置にドラッグし、接続すると、コネクタは最も近い辺の間をきちんと通ります。

設計によるプライベート： このツールのすべてはJavaScriptでブラウザ内で100%行われます。データ、写真、デザインがサーバーにアップロードされることは決してなく、保存されることも、私たちに見られることもありません - タブを閉じればすべてが消えます。

フローチャートメーカーの使い方

  1. 上部のボタンで図形を追加してください — 開始/終了、プロセス、判断、入力/出力、ドキュメント。
  2. 各図形を位置にドラッグし、クリックして下のエディターでテキストと正確なサイズを編集してください。
  3. 二つの図形をつなぐには：最初の図形を選択し、「Connect selected」を押し、対象の図形をクリックします。コネクタは最も近い辺を選び、きれいなエルボーで自動的に経路を決めます。
  4. コネクタを選択し（既に選択された状態で作成されます）、「はい」や「いいえ」のようなラベルを入力してください。グラフが明確に読めたらPNGをダウンロードします。

仕組み

コネクタは幾何学的に計算されます：任意の二つの図形について、メーカーは十六組すべての辺のアンカー（各図形の上、下、左、右）を比較し、最も近いペアを選び、中点を通る直角の肘を通します — そのため、図形をどこにドラッグしても矢印はきちんとしたままです。矢印の先端は最終セグメントの角度から描かれます。すべてはブラウザー内のキャンバス上にベクター描画されます。何もアップロードされません。

実例

ある学校の事務員が入学手続きをマッピングします：開始 → 申込書を記入（ドキュメント）→ 書類は揃っていますか？（判断）— はいは受講料の支払いへ、いいえは家族を「不足書類を用意」プロセスボックスへ戻します。PNGはオフィスの掲示板用に印刷されます。

よくある質問

マインドマップメーカーとの違いは？

マインドマップは一つの中心からアイデアを分岐させます。フローチャートは方向のある矢印で順序のあるステップと判断を示します — プロセス、アルゴリズム、手順に使ってください。

コネクタは経路をどう選びますか？

自動的に — メーカーは二つの図形のすべての辺のペア間の距離を測定し、最も近いペアの間に肘型コネクタを通します。ドラッグすると更新されます。

判断の分岐にラベルを付けられますか？

はい — 接続後、新しいコネクタが選択されます；コネクタラベルボックスにYes、No、または任意のラベルを入力してください。

フローチャートを保存できますか？

完成したグラフのPNGをダウンロードしてください。タブが開いている間、図は編集可能です。

フローチャートメーカーは無料ですか？

はい — 無料、登録不要、透かしなし、そしてダイアグラムがデバイスを離れることは決してありません。
