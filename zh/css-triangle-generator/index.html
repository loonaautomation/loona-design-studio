CSS 三角形生成器 — 四个方向的边框技巧三角形

简言之： CSS 三角形生成器产生著名的边框技巧三角形——一个零尺寸元素，其粗边框相遇成一个完美的箭头——四个方向、任何大小和颜色。

如何使用CSS 三角形生成器

  1. 选择三角形指向的方向。
  2. 设置大小（箭头的完整高度）和颜色。
  3. 复制 CSS——元素不需要内容，只需要这个类。

工作原理

一个 0 × 0 元素的四条边框是四个在中心相交的三角形。让三条边框透明、一条着色，就得到一个三角形；边框宽度决定其比例（等腰箭头的两侧边框是主尺寸的一半）。

常见问题

为什么使用 CSS 三角形而不是图片或表情符号？

它们缩放、用一个值重新着色、即时加载并保持清晰——并自动继承主题（深色模式）。

我可以做一个角丝带三角形吗？

是的——直角情形是两条着色的边框；从复制的模式开始，再把多余的一边宽度归零。

它适用于工具提示吗？

完美地——把三角形放在工具提示边缘；这是标准技巧。

输出是标准的吗？

是的——普通边框 CSS，一直受支持。
