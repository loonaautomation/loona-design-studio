证书制作工具 — 免费可打印证书，单张或批量制作

简而言之：证书制作工具可创建可直接打印的 A4 横向证书 — 选择模板、输入姓名、打印即可。需要为整个班级或整期课程制作？粘贴 CSV 名单，它会自动为每个人生成一张证书。

学校、学院、培训中心和小型团队每周都要颁发证书，通常使用的工具速度慢、一次只能做一张。这款制作工具能胜任两种工作：一分钟内做出一张精美的证书，或从电子表格批量生成整批证书 — 姓名、课程和日期都会为您自动填好。

请粘贴包含 name、course、date 三列的 CSV 内容（表头行可省略），或上传 .csv 文件。表单中的模板、样式、说明文字、颁发机构和签署人将用于每一张证书。

注重隐私的设计：此工具中的一切操作 100% 通过 JavaScript 在您的浏览器中完成。您的姓名、班级名单和设计绝不会上传到服务器，绝不会被存储，我们也绝不会看到 — 关闭标签页后，一切都会消失。

如何使用证书制作工具

  1. 选择模板和样式，然后输入获奖者姓名、课程或活动名称、日期、颁发机构和签署人。预览会随着您的输入实时更新。
  2. 如需单张证书，请点击“下载 PNG”获取高分辨率图片，或点击“打印 / 另存为 PDF”获得清晰的 A4 横向页面。
  3. 如需批量制作，请切换到“通过 CSV 批量生成”，粘贴您的名单（name, course, date）或上传 .csv 文件，然后点击“生成证书”。
  4. 在批量结果中逐张浏览以下载单张 PNG，或选择“打印全部证书”，按每页一张的方式打印。

工作原理

每张证书都以精确的 A4 横向比例（297 × 210 毫米）绘制为矢量设计，因此文字在任何打印尺寸下都保持清晰。在批量模式下，制作工具会在本地读取您的 CSV 行，将同一设计逐人填充，并准备好每页一张证书的打印版面。较长的姓名会自动适配设计。任何内容都不会上传 — 即使有数百个姓名，整批证书也全部在您的设备上生成。

完整示例

一位老师为 28 名学生完成了为期两周的计算机课程。她将班级名单导出为 CSV，粘贴到批量模式中，选择 Classic 金色，然后一次性打印全部 28 张证书 — 每张都带有学生姓名、课程名称和相同日期 — 用时比过去制作一张证书还要短。

常见问题

批量模式需要什么 CSV 格式？

三列：name、course、date — 按此顺序排列。带有这些名称的表头行可省略。包含逗号的字段可以用双引号括起来，与电子表格应用导出的格式完全一致。

可以添加真实签名吗？

输入签署人姓名后，姓名会以优雅的手写体样式绘制在签名线上方。如需手写签名，请打印证书后亲手签署 — 大多数学校和学院都更喜欢这种方式。

证书以什么尺寸打印？

A4 横向（297 × 210 毫米），每页一张证书。PNG 下载尺寸为 3369 × 2382 像素，清晰度足以满足专业印刷需求。

我的班级名单是私密的吗？

可以 — CSV 在您的浏览器内读取，绝不会上传。姓名和名单始终保留在您的设备上。
