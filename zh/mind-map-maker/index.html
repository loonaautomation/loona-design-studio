思维导图制作工具 — 免费在线思维导图，带自动布局

简言之： 思维导图制作工具从一个中心想法生长出整洁的图：点击任何节点，用按钮或键盘添加子节点和同级节点，树会自动重新布局——然后导出 PNG 或把地图保存为 JSON 以便以后继续。

课程规划、作文结构、项目分解、复习笔记——思维导图把纠缠的话题变成一幅图。把大想法放在中间，向外分支；工具在您思考时保持一切整洁。

点击一个节点选中它。拖动空白处平移。每次更改后布局会自动整理。

按设计私密： 这个工具中的一切 100% 在您的浏览器中使用 JavaScript 进行。您的数据、照片和设计从不上传到服务器，从不存储，也从不被我们看到——关闭标签页，一切都消失。

如何使用思维导图制作工具

  1. 点击中心节点，在所选节点文本框中输入您的主要想法。
  2. 按添加子节点（或 Tab 键）从所选节点分支；按添加同级节点（或 Enter）在同一级别得到一个节点。
  3. 点击任何节点编辑其文字。拖动空白处平移，使用缩放或适应来框住整个图。
  4. 下载 PNG 分享或打印，或另存为 JSON 以后加载回来继续编辑。

工作原理

地图是节点的树。一个整洁的布局算法测量每个分支：一个分支与其孩子以均匀间距堆叠一样高，父母位于其孩子旁边居中，每级有自己的列——因此无论树如何生长，方框永不重叠。边缘绘制为平滑曲线。导出把相同的布局渲染到一张按地图精确大小的新画布上，JSON 保存/加载把整棵树存储为您可以保存在任何地方的纯文本。

实例

一位规划科学单元的老师以“水循环”为中心，添加子节点蒸发、凝结、降水和汇集，再为每个子节点添加两个细节节点。完成的 PNG 成为课堂讲义，JSON 文件让她下学期能扩展同一张图。

常见问题

如何快速添加节点？

选择一个节点，按 Tab 得子节点或 Enter 得同级节点。画布上方的按钮在触摸屏上做同样的事。

我可以保存思维导图以后继续吗？

是的——另存为 JSON 下载整个地图。使用加载选择器再次打开它并继续编辑。

大地图会保持可读吗？

布局从不重叠方框，您可以平移、缩放和使用适合视图查看一切。PNG 导出按完整地图定尺寸，因此什么都不会被切掉。

我的思维导图私密吗？

完全私密——图只存在于您的浏览器中。我们不会上传或存储任何内容。

我可以改变颜色吗？

是的——五种主题（青色与金色、海洋、日落、葡萄和单色）即时重塑整个地图。
