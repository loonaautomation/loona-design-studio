图表制作工具 — 免费条形图、折线图、饼图与环形图

简言之： 图表制作工具把一个小表格（或粘贴的 CSV）变成在您浏览器中画布上绘制的干净条形图、折线图、饼图和环形图，带逐系列颜色、自定义标题、可选图例和一键 PNG 导出。

报告、家庭作业、预算和演示都需要同一件事：一眼就能理解的数字。把您的数字输入可编辑网格——或粘贴 CSV——选择图表类型，下载一张清晰的 PNG 用于您的文件、幻灯片或社交帖子。

按设计私密： 这个工具中的一切 100% 在您的浏览器中使用 JavaScript 进行。您的数据、照片和设计从不上传到服务器，从不存储，也从不被我们看到——关闭标签页，一切都消失。

如何使用图表制作工具

  1. 把您的标签和数字输入网格，或把 CSV 粘贴到图表下方的框中并按应用 CSV。
  2. 选择图表类型：条形图或折线图用于比较和趋势，饼图或环形图用于总计的份额（它们使用第一个系列）。
  3. 设置图表标题，切换图例，给每个系列自己的颜色。
  4. 按下载图表 PNG，把图片放入您的文件、幻灯片或帖子。使用把我的数据复制为 CSV 来保存您的数字以备后用。

工作原理

图表在 HTML 画布上手工绘制——没有图表库，也没有服务器。数值按圆整的“漂亮”最大值（十的幂的 1、2、2.5、5 或 10 倍）缩放，让轴标签保持可读。饼图和环形图切片是系列总计的精确比例：每个切片角度 = 数值 ÷ 总计 × 360 度。一切都在本地计算，因此您的数字永远不会离开您的设备。

实例

一位班主任输入每月测验平均分——一月 62、二月 68、三月 71、四月 75——作为一个系列，再把班级目标作为第二个系列。折线图显示进度在四月越过目标，PNG 直接放进了学校报告。

常见问题

这个图表制作工具免费吗？

是的——完全免费，没有注册，没有水印，也没有您可以制作的图表数量限制。

我的数字会被上传到任何地方吗？

不。图表 100% 在您的浏览器中绘制。您的数据从不离开您的设备。

应该使用哪种图表类型？

使用条形图比较类别，折线图看随时间的变化，饼图或环形图看一个总计的组成部分（它们显示第一个数据系列）。

我可以从电子表格粘贴数据吗？

是的——从 Excel 或 Google Sheets 复制单元格并粘贴到 CSV 框中，然后按应用 CSV。第一行应包含系列名称，第一列是标签。

导出的 PNG 尺寸是多少？

图表以 920 × 560 像素导出，对文件、幻灯片和社交帖子足够清晰。
