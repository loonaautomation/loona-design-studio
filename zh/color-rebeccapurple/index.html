用好 Rebecca Purple

Rebecca Purple 属于紫色 / 紫罗兰色色系，明度为 40%——一种中间色调、中度饱和、凉的颜色。作为背景，它与白色文字搭配最好（对比度 8.41:1）。其互补色（#669933）是行动号召和高亮的高能量伙伴；类似色邻居（#333399、#993399）给出平静的同色系渐变。印刷时，从上面的 CMYK 值开始并校样——屏幕上的 Rebecca Purple 是 sRGB 颜色，浓郁的屏幕色调在印刷时可能发生偏移。

常见问题

Rebecca Purple 的十六进制代码是什么？

#663399 —— CSS 命名颜色“rebeccapurple”。其 RGB 为 (102, 51, 153)。

Rebecca Purple 适合用作文字还是背景？

作为背景，白色文字在它上面读起来最好（8.41:1）。作为文字本身，在白色上它达到 8.41:1——足以满足 WCAG AA 普通文字。

什么颜色与 Rebecca Purple 相配？

其互补色 #669933 用于对比，类似色 #333399 和 #993399 用于平静的组合，以及上面的 50–950 色阶用于单色设计。

Rebecca Purple 的印刷 CMYK 是多少？

C33 M67 Y0 K40。屏幕颜色的 CMYK 转换是一个起点——印刷前始终先校样再批量印刷。
