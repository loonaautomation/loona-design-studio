用好 Lightyellow

Lightyellow 属于黄色色系，明度为 94%——一种浅、鲜艳、暖的颜色。作为背景，它与黑色文字搭配最好（对比度 20.63:1）。其互补色（#E0E0FF）是行动号召和高亮的高能量伙伴；类似色邻居（#FFF0E0、#F0FFE0）给出平静的同色系渐变。印刷时，从上面的 CMYK 值开始并校样——屏幕上的 Lightyellow 是 sRGB 颜色，浓郁的屏幕色调在印刷时可能发生偏移。

常见问题

Lightyellow 的十六进制代码是什么？

#FFFFE0 —— CSS 命名颜色“lightyellow”。其 RGB 为 (255, 255, 224)。

Lightyellow 适合用作文字还是背景？

作为背景，黑色文字在它上面读起来最好（20.63:1）。作为文字本身，在白色上它达到 1.02:1——对 AA 级正文文字不够；请把它用于标题、大文字或强调。

什么颜色与 Lightyellow 相配？

其互补色 #E0E0FF 用于对比，类似色 #FFF0E0 和 #F0FFE0 用于平静的组合，以及上面的 50–950 色阶用于单色设计。

Lightyellow 的印刷 CMYK 是多少？

C0 M0 Y12 K0。屏幕颜色的 CMYK 转换是一个起点——印刷前始终先校样再批量印刷。
