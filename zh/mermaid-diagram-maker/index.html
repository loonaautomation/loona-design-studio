Mermaid 图表制作工具 — 粘贴 Mermaid 代码，得到图表

简言之： 这个 Mermaid 图表制作工具解析 Mermaid 语法的流程图子集——graph 方向、[ ]、( )、{ } 和 (( )) 形状的带标签节点、带 |labels| 的箭头——并渲染一个您可以下载为 PNG 的分层图表。解析器完全在您的浏览器中运行。

开发者和技术作家在文档和 AI 聊天中把图表描述为 Mermaid 文本。当您只需要图片时——用于幻灯片、文档或快速审查——把代码粘贴到这里，而不是搭建一整套工具链。

按设计私密： 这个工具中的一切 100% 在您的浏览器中使用 JavaScript 进行。您的数据、照片和设计从不上传到服务器，从不存储，也从不被我们看到——关闭标签页，一切都消失。

如何使用Mermaid 图表制作工具

  1. 在框中粘贴或编写 Mermaid 流程图代码。以 graph TD（自上而下）或 graph LR（从左到右）开始。
  2. 使用支持的形状：A[Process]、B(Rounded)、C{Decision}、D((Circle))——以及连接 A --> B 或 A -->|label| B。
  3. 图表以分层布局实时渲染；任何超出支持子集的行都会报告在画布下方，从不被悄悄丢弃。
  4. 按图表的完整自然尺寸下载 PNG。

工作原理

手写解析器逐行读取节点标记和连接，然后分层布局通过从根（没有入射箭头的节点）开始的广度优先搜索给每个节点分配深度，并按顺序打包每级。支持：flowchart/graph 头部（TD、TB、BT、LR、RL）、本页列出的节点形状、实线和带标签的箭头，以及普通链接（---）。不支持（按设计，并诚实说明）：时序图、类图、状态图和甘特图、子图和样式指令——这些行会在状态行中标记，而不是被错误渲染。

实例

一个 AI 聊天给一位开发者生成了结账流程的 Mermaid 代码。她把代码粘贴到这里，检查决策分支是否按预期渲染，然后把 PNG 放进团队的设计文档。

常见问题

支持哪些 Mermaid 语法？

流程图子集：graph/flowchart TD/TB/BT/LR/RL，节点 A[..]、A(..)、A{..}、A((..))、A[[..]]，连接 -->、---、-.、==> 变体，以及 |labels|。时序图/类图/甘特图不是这个渲染器的一部分——页面会在某行不受支持时告诉您。

为什么不使用完整的 Mermaid 库？

本页是手工打造的，以保持完全自包含和快速，零外部依赖，涵盖大多数人粘贴的流程图子集。完整的 Mermaid.js 库涵盖更多图表类型。

不支持的行会怎样？

它们会被收集并在画布下方的状态行中报告（“第 N 行：不在支持的子集内”）——从不被悄悄忽略。

我的代码会被上传吗？

不——解析和渲染 100% 在您的浏览器中进行。
