工作原理

圆环和圆弧加载动画用 keyframes 动画旋转整圈；圆弧使用被遮罩成圆环的 conic-gradient，使其尾部几何地淡出。圆点在一次弹跳 keyframe 上使用交错的动画延迟——延迟，而不是单独的动画，创造了波浪。

常见问题

哪个加载动画最专业？

中等速度（0.8–1 秒）的圆环是企业标准。圆点感觉更友好；圆弧感觉最现代。

它会尊重减少动态效果的设置吗？

在 CSS 中添加媒体查询：@media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } }——减慢而不是移除，能保留含义。

我以后可以改变速度吗？

是的——复制的 CSS 中的一个数字（动画时长）。

纯 CSS——没有 JavaScript？

正确。预览使用工具导出的同一套 CSS。
