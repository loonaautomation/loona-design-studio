用好 Darkorchid

Darkorchid 属于紫色 / 紫罗兰色色系，明度为 50%——一种中间色调、中度饱和、凉的颜色。作为背景，它与白色文字搭配最好（对比度 5.70:1）。其互补色（#65CC32）是行动号召和高亮的高能量伙伴；类似色邻居（#4C32CC、#CC32B2）给出平静的同色系渐变。印刷时，从上面的 CMYK 值开始并校样——屏幕上的 Darkorchid 是 sRGB 颜色，浓郁的屏幕色调在印刷时可能发生偏移。

常见问题

Darkorchid 的十六进制代码是什么？

#9932CC —— CSS 命名颜色“darkorchid”。其 RGB 为 (153, 50, 204)。

Darkorchid 适合用作文字还是背景？

作为背景，白色文字在它上面读起来最好（5.70:1）。作为文字本身，在白色上它达到 5.70:1——足以满足 WCAG AA 普通文字。

什么颜色与 Darkorchid 相配？

其互补色 #65CC32 用于对比，类似色 #4C32CC 和 #CC32B2 用于平静的组合，以及上面的 50–950 色阶用于单色设计。

Darkorchid 的印刷 CMYK 是多少？

C25 M75 Y0 K20。屏幕颜色的 CMYK 转换是一个起点——印刷前始终先校样再批量印刷。
