Penjana Kecerunan Mesh — Latar Belakang Kecerunan Aurora / Gumpalan dalam CSS

Ringkasnya: Penjana Kecerunan Mesh melapiskan empat blob kecerunan jejari lembut di atas warna asas — rupa aurora latar belakang aplikasi moden — dan mengeksportnya sebagai CSS tulen tanpa fail imej.

Kecerunan mesh membuat halaman rata terasa hidup, tetapi menulis empat kecerunan jejari berlapis dengan tangan adalah penderitaan. Seret gumpalan di sini, salin dua baris CSS, selesai.

Beberapa kecerunan jejari lembut ("gumpalan") dilapisi di atas warna asas. Alihkan setiap gumpalan, ubah saiz cahayanya, warnakan semula.

Peribadi secara reka bentuk: semua dalam alat ini berlaku 100% dalam pelayar anda dengan JavaScript. Data, foto dan reka bentuk anda tidak pernah dimuat naik ke pelayan, tidak pernah disimpan dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Cara menggunakan Penjana Kecerunan Mesh

  1. Warnakan semula asas — ia kelihatan di mana-mana gumpalan memudar.
  2. Untuk setiap gumpalan: pilih warnanya, kedudukan (x/y) dan saiz cahayanya.
  3. Salin CSS. Baris background-color mengecat asas; background-image menindan gumpalan.

Cara ia berfungsi

Setiap gumpalan ialah kecerunan jejari yang diletakkan mengikut peratusan dengan pudar lutsinar; menindannya di atas asas padu menghasilkan mesh. Kerana ia CSS tulen, latar belakang berskala kepada sebarang skrin dengan berat imej sifar.

Contoh terkerja

Hero laman portfolio berubah daripada gelap biasa kepada aurora teal-emas yang menggemakan logo pemiliknya — dua baris CSS, tiada muat turun imej.

Soalan Lazim

Mesh lawan kecerunan biasa?

Kecerunan linear sebati di sepanjang satu garis. Mesh menyebatikan beberapa kolam warna dalam dua dimensi — lebih lembut, lebih organik, lebih "aurora".

Adakah ia akan melambatkan halaman saya?

Tidak — ia ialah rendering CSS tulen, tiada fail imej langsung.

Bolehkah saya menambah lebih banyak gumpalan?

Empat gumpalan meliputi kebanyakan reka bentuk. Corak CSS yang dieksport mudah dikembangkan dengan menyalin sebutan kecerunan jejari.

Adakah ia berfungsi pada mudah alih?

Ya — kedudukan peratusan menjadikannya responsif sepenuhnya.
