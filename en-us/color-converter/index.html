Color Converter — HEX, RGB, HSL, HSV & CMYK (Extended)

In short: the Color Converter shows one color in every major notation at once — HEX, RGB, HSL, HSV/HSB and CMYK — plus relative luminance and its contrast ratio against black and white.

Designers think in HEX, printers ask for CMYK, CSS wants HSL, and accessibility is judged by contrast. This extended converter keeps all of them on one screen so nothing is lost between tools.

Private by design: everything in this tool happens 100% in your browser with JavaScript. Your data, photos and designs are never uploaded to a server, never stored and never seen by us - close the tab and everything is gone.

How to use the Color Converter

  1. Type a HEX color or use the picker.
  2. Read every notation in the grid — each is computed from the same color, so they always agree.
  3. Copy the full block, or just the line you need.

How it works

Conversions use the standard color-space mathematics: HSL/HSV from normalized RGB, CMYK by the usual K-extraction formula, and WCAG relative luminance (with gamma correction) for the contrast ratios — the same numbers accessibility checkers report.

Worked example

A developer receives a brand color as HEX from a designer, needs CMYK for the printer and an HSL for CSS hover states — one paste here answers all three, with the contrast check as a bonus.

Frequently Asked Questions

Which format is "correct"?

All of them describe the same color. HEX/RGB for screens, HSL for design adjustments, CMYK for print, HSV for pickers.

What is a good contrast ratio?

WCAG asks for at least 4.5:1 for normal text against its background. Check your text color against white and black in the grid.

Does CMYK here match my printer exactly?

It is the standard mathematical conversion — a strong starting point. Professional print uses ICC profiles for final proofing.

Can I enter RGB instead?

Use the color picker, which covers the full RGB space, or the Shades tool’s picker — the HEX updates everywhere.
