Generador de spinners de carga CSS — Anillo, arco y puntos (CSS puro)

En resumen: el Generador de spinners CSS crea animaciones de carga en CSS puro — un anillo clásico, un arco cónico enmascarado o puntos con rebote — con controles de tamaño, grosor, color y velocidad, y exporta el CSS completo incluidos los keyframes.

Cada app necesita un estado de carga, y los spinners GIF son pesados y borrosos. Estos tres spinners son unas pocas líneas de CSS cada uno: sin peso, nítidos a cualquier tamaño y recoloreados con un solo valor.

Privado por diseño: todo en esta herramienta ocurre 100% en tu navegador con JavaScript. Tus datos, fotos y diseños nunca se suben a un servidor, nunca se guardan y nunca los vemos nosotros: cierra la pestaña y todo desaparece.

Cómo usar Generador de spinners CSS

  1. Elige un estilo: Anillo para lo clásico, Arco para lo moderno minimalista, Puntos para lo amable.
  2. Ajusta tamaño, grosor, color y velocidad: la vista previa ejecuta la animación real.
  3. Copia el CSS. Para el estilo de puntos, el fragmento HTML se incluye como comentario en la salida.

Cómo funciona

Los spinners de anillo y arco giran un círculo completo con una animación de keyframes; el arco usa un conic-gradient enmascarado en un anillo para que su cola se desvanezca geométricamente. Los puntos usan retardos de animación escalonados en un keyframe de rebote: el retardo, no animaciones separadas, crea la onda.

Preguntas frecuentes

¿Qué spinner es más profesional?

El anillo a velocidad moderada (0.8–1s) es el estándar corporativo. Los puntos se sienten más amables; el arco se siente el más moderno.

¿Respetará los ajustes de movimiento reducido?

Añade una media query en tu CSS: @media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } }: ralentizar, no eliminar, conserva el significado.

¿Puedo cambiar la velocidad después?

Sí: un número (la duración de la animación) en el CSS copiado.

¿CSS puro, sin JavaScript?

Correcto. La vista previa usa el mismo CSS que la herramienta exporta.
