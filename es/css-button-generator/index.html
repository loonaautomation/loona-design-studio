Generador de botones CSS — Diseña botones y obtén el código

En resumen: el Generador de botones CSS diseña un botón completo — fondo, texto, relleno, radio de esquina, borde, negrita — y escribe CSS de producción incluido un estado hover más oscuro automático.

Los botones son el elemento más tocado de cualquier sitio y el más complicado de estilizar a prueba y error. Diseña el tuyo aquí una vez; incluso el color al pasar el ratón se deriva por ti.

Privado por diseño: todo en esta herramienta ocurre 100% en tu navegador con JavaScript. Tus datos, fotos y diseños nunca se suben a un servidor, nunca se guardan y nunca los vemos nosotros: cierra la pestaña y todo desaparece.

Cómo usar Generador de botones CSS

  1. Da estilo al botón de vista previa: primero los colores, luego el tamaño (relleno y texto), luego las esquinas y el borde.
  2. El tono al pasar el ratón es tu fondo oscurecido en un paso fijo: comprueba que se siente bien pasando el ratón sobre el área de vista previa en tu propio proyecto.
  3. Copia el CSS y renombra .my-button con tu clase.

Cómo funciona

El color al pasar el ratón se calcula restando una cantidad fija de cada canal RGB del fondo (limitado al negro), una regla fiable de «mismo tono, más profundo». El relleno se divide en valores vertical y horizontal porque los grandes botones son más anchos que altos.

Ejemplo trabajado

El botón de donar de un sitio benéfico pasa del azul por defecto a un botón de marca grande, con el radio dorado: la página de donaciones por fin coincide con los pósteres.

Preguntas frecuentes

¿Por qué el hover es más oscuro, no más claro?

Oscurecer al pasar el ratón se lee como «presionar hacia abajo» bajo la misma luz: la convención que los usuarios esperan inconscientemente.

¿Puedo hacer un botón pastilla?

Ajusta el radio de esquina a su máximo (40) con una altura modesta: una pastilla completa.

¿Puedo hacer un botón de contorno (fantasma)?

Ajusta un ancho de borde y luego usa el truco de la página de Box Shadow: en realidad ajusta el fondo al color de tu página y el texto al color de marca, o simplemente intercambia los dos valores de color en el CSS copiado.

¿El CSS es independiente de frameworks?

Sí: CSS simple, funciona en cualquier parte, sin dependencias.
