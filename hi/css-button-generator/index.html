CSS बटन जनरेटर — बटन डिज़ाइन करें, कोड पाएँ

संक्षेप में: CSS Button Generator पूरा बटन डिज़ाइन करता है — पृष्ठभूमि, पाठ, पैडिंग, कोना त्रिज्या, बॉर्डर, बोल्ड — और स्वतः गहरे होवर स्थिति सहित उत्पादन CSS लिखता है।

बटन किसी भी साइट का सबसे अधिक छुआ जाने वाला तत्व हैं और परीक्षण-और-त्रुटि से स्टाइल करने में सबसे अधिक झंझट वाले। अपना यहाँ एक बार डिज़ाइन करें; होवर रंग भी आपके लिए निकाला जाता है।

डिज़ाइन से निजी: इस टूल में सब कुछ JavaScript के साथ 100% आपके ब्राउज़र में होता है। आपका डेटा, फ़ोटो और डिज़ाइन कभी सर्वर पर अपलोड नहीं होते, कभी संग्रहीत नहीं होते और कभी हमारे द्वारा नहीं देखे जाते - टैब बंद करें और सब कुछ गया।

CSS बटन जनरेटर का उपयोग कैसे करें

  1. पूर्वावलोकन बटन स्टाइल करें: पहले रंग, फिर आकार (पैडिंग और पाठ), फिर कोने और बॉर्डर।
  2. होवर शेड निश्चित चरण से गहरी आपकी पृष्ठभूमि है — अपने प्रोजेक्ट में पूर्वावलोकन क्षेत्र पर होवर करके जाँचें कि यह सही लगे।
  3. CSS कॉपी करें और .my-button का नाम अपनी क्लास से बदलें।

यह कैसे काम करता है

होवर रंग पृष्ठभूमि के प्रत्येक RGB चैनल से निश्चित मात्रा घटाकर परिकलित होता है (काले पर सीमित), विश्वसनीय "वही रंग, गहरा" नियम। पैडिंग ऊर्ध्वाधर और क्षैतिज मानों में विभाजित है क्योंकि अच्छे बटन अपने ऊँचे होने से अधिक चौड़े होते हैं।

हल किया उदाहरण

एक चैरिटी साइट का दान बटन डिफ़ॉल्ट नीले से बदलकर बड़ा, सुनहरी-त्रिज्या वाला ब्रांड बटन बन जाता है — दान पृष्ठ आखिरकार पोस्टरों से मेल खाता है।

अक्सर पूछे जाने वाले प्रश्न

होवर गहरा क्यों है, हल्का क्यों नहीं?

होवर पर गहरा होना उसी प्रकाश में "दबाने" जैसा पढ़ा जाता है — वह परिपाटी जिसकी उपयोगकर्ता अचेतन रूप से अपेक्षा करते हैं।

क्या मैं गोली बटन बना सकता हूँ?

मामूली ऊँचाई के साथ कोना त्रिज्या अधिकतम (40) पर सेट करें — पूरा पिल।

क्या मैं आउटलाइन (घोस्ट) बटन बना सकता हूँ?

बॉर्डर चौड़ाई सेट करें, फिर Box Shadow पृष्ठ की तरकीब उपयोग करें: वास्तव में पृष्ठभूमि को अपने पृष्ठ रंग और पाठ को ब्रांड रंग पर सेट करें — या कॉपी किए CSS में दो रंग मान बदल दें।

क्या CSS फ़्रेमवर्क-मुक्त है?

हाँ — सादा CSS, हर जगह काम करता है, कोई निर्भरता नहीं।
