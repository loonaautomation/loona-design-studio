CSS लोडिंग स्पिनर जनरेटर — रिंग, आर्क और बिंदु (शुद्ध CSS)

संक्षेप में: CSS Spinner Generator शुद्ध-CSS लोडिंग एनिमेशन बनाता है — क्लासिक वलय, मास्क किया कोनिक चाप, या उछलते बिंदु — आकार, मोटाई, रंग और गति नियंत्रण के साथ, और keyframes सहित पूर्ण CSS निर्यात करता है।

हर ऐप को लोडिंग स्थिति चाहिए, और GIF स्पिनर भारी और धुंधले होते हैं। ये तीन स्पिनर प्रत्येक CSS की कुछ पंक्तियाँ हैं: भारहीन, किसी भी आकार पर तीखे, और एक मान में पुनः रंगित।

डिज़ाइन से निजी: इस टूल में सब कुछ JavaScript के साथ 100% आपके ब्राउज़र में होता है। आपका डेटा, फ़ोटो और डिज़ाइन कभी सर्वर पर अपलोड नहीं होते, कभी संग्रहीत नहीं होते और कभी हमारे द्वारा नहीं देखे जाते - टैब बंद करें और सब कुछ गया।

CSS स्पिनर जनरेटर का उपयोग कैसे करें

  1. शैली चुनें: क्लासिक के लिए रिंग, आधुनिक न्यूनतम के लिए आर्क, मैत्रीपूर्ण के लिए बिंदु।
  2. आकार, मोटाई, रंग और गति सेट करें — पूर्वावलोकन असली एनिमेशन चलाता है।
  3. CSS कॉपी करें। बिंदु शैली के लिए, HTML स्निपेट आउटपुट में टिप्पणी के रूप में शामिल है।

यह कैसे काम करता है

वलय और चाप स्पिनर keyframes एनिमेशन के साथ पूरा वृत्त घुमाते हैं; चाप conic-gradient को वलय में मास्क करके उपयोग करता है ताकि उसकी पूंछ ज्यामितीय रूप से फीकी पड़े। बिंदु एक बाउंस keyframe पर क्रमिक एनिमेशन विलंब उपयोग करते हैं — विलंब, अलग एनिमेशन नहीं, लहर बनाता है।

हल किया उदाहरण

एक टूल साइट अपने GIF लोडर को यहाँ के 54 px टील रिंग से बदल देती है — पृष्ठ 180 KB हल्का हो जाता है और स्पिनर ब्रांड से मेल खाता है।

अक्सर पूछे जाने वाले प्रश्न

कौन सा स्पिनर सबसे पेशेवर है?

मध्यम गति (0.8–1s) पर वलय कॉर्पोरेट मानक है। बिंदु मैत्रीपूर्ण लगते हैं; चाप सबसे आधुनिक लगता है।

क्या यह रिड्यूस्ड-मोशन सेटिंग का सम्मान करेगा?

अपने CSS में मीडिया क्वेरी जोड़ें: @media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } } — धीमा करना, हटाना नहीं, अर्थ बनाए रखता है।

क्या मैं बाद में गति बदल सकता हूँ?

हाँ — कॉपी किए CSS में एक नंबर (एनिमेशन अवधि)।

शुद्ध CSS — कोई JavaScript नहीं?

सही। पूर्वावलोकन वही CSS उपयोग करता है जो टूल निर्यात करता है।
