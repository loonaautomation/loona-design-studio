How to use Desert Dunes

Sun-baked neutrals — sand, clay and one oasis teal.

Best for: Travel, outdoor gear, natural cosmetics and slow-living brands.

Watch out: All-neutral layouts can look washed out on cheap screens — keep the deep oasis in every layout for structure.

The 60-30-10 split

Use the palette's light neutral for ~60% of any layout (backgrounds and space), the primary for ~30% (sections, cards, secondary elements), and reserve the strongest accent for ~10% (buttons, highlights, the one thing each screen must sell). A palette fails when every colour shouts at equal volume — the roles above are ordered to prevent exactly that.

Frequently Asked Questions

Can I use the Desert Dunes palette commercially?

Yes — colour palettes are not copyrightable as combinations of standard colours, and Loona places no restriction on using these values in any project.

What is the primary colour of this palette?

#BC6C25 (Clay) carries the brand; #606C38 anchors text and depth.

How do I know text will be readable?

Each swatch shows its RGB; pair text using the deep base on light neutrals. For exact ratios, paste any two values into the Colour Converter's contrast checker pattern — or compare against the per-colour pages, which publish WCAG contrast for all 141 named colours.

Can I change one colour?

Keep the structure (one deep anchor, one primary, one accent, lights) and swap within the same lightness band — that preserves the palette's logic while making it yours.
