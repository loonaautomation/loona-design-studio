CSS লোডিং স্পিনার জেনারেটর — রিং, আর্ক ও ডটস (খাঁটি CSS)

সংক্ষেপে: CSS স্পিনার জেনারেটর খাঁটি-CSS লোডিং অ্যানিমেশন তৈরি করে — একটি ধ্রুপদি রিং, একটি মুখোশ পরা কনিক আর্ক, বা লাফানো ডট — আকার, পুরুত্ব, রঙ ও গতি নিয়ন্ত্রণসহ, এবং keyframes-সহ সম্পূর্ণ CSS এক্সপোর্ট করে।

প্রতিটি অ্যাপের একটি লোডিং অবস্থা দরকার, এবং GIF স্পিনার ভারী ও ঝাপসা। এই তিনটি স্পিনারের প্রতিটি কয়েক লাইন CSS: ওজনহীন, যেকোনো আকারে ধারালো, এবং এক মানে আবার রঙ করা।

ডিজাইন অনুযায়ী ব্যক্তিগত: এই টুলে সবকিছু JavaScript দিয়ে 100% আপনার ব্রাউজারে ঘটে। আপনার ডেটা, ছবি ও ডিজাইন কখনো একটি সার্ভারে আপলোড হয় না, কখনো সংরক্ষিত হয় না এবং কখনো আমাদের দ্বারা দেখা হয় না - ট্যাব বন্ধ করুন এবং সবকিছু চলে গেছে।

CSS স্পিনার জেনারেটর কীভাবে ব্যবহার করবেন

  1. একটি স্টাইল বেছে নিন: ধ্রুপদির জন্য রিং, আধুনিক মিনিমালের জন্য আর্ক, বন্ধুত্বপূর্ণর জন্য ডটস।
  2. আকার, পুরুত্ব, রঙ ও গতি সেট করুন — প্রিভিউ আসল অ্যানিমেশন চালায়।
  3. CSS কপি করুন। ডটস স্টাইলের জন্য HTML স্নিপেট আউটপুটে একটি মন্তব্য হিসেবে অন্তর্ভুক্ত আছে।

এটি কীভাবে কাজ করে

রিং ও আর্ক স্পিনার একটি keyframes অ্যানিমেশন দিয়ে একটি সম্পূর্ণ বৃত্ত ঘোরে; আর্ক একটি কনিক-গ্রেডিয়েন্ট ব্যবহার করে একটি রিংয়ে মুখোশ পরা যাতে এর লেজ জ্যামিতিকভাবে ম্লান হয়। ডটস একটি বাউন্স keyframe-এ স্তব্ধ অ্যানিমেশন বিলম্ব ব্যবহার করে — বিলম্ব, আলাদা অ্যানিমেশন নয়, তরঙ্গ তৈরি করে।

কাজ করা উদাহরণ

একটি টুলস সাইট তার GIF লোডার বদলে এখানকার 54 px টিল রিং ব্যবহার করে — পেজ 180 KB ঝরিয়ে ফেলে এবং স্পিনার ব্র্যান্ডের সঙ্গে মিলে যায়।

প্রায়ই জিজ্ঞাসিত প্রশ্ন

কোন স্পিনার সবচেয়ে পেশাদার?

মাঝারি গতিতে রিং (0.8–1s) কর্পোরেট মান। ডটস বন্ধুসুলভ মনে হয়; আর্ক সবচেয়ে আধুনিক মনে হয়।

এটি কি reduced-motion সেটিংস সম্মান করবে?

আপনার CSS-এ একটি মিডিয়া কোয়েরি যোগ করুন: @media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } } — ধীর করা, সরিয়ে নয়, অর্থ বজায় রাখে।

আমি কি পরে গতি বদলাতে পারি?

হ্যাঁ — কপি করা CSS-এ একটি সংখ্যা (অ্যানিমেশনের সময়কাল)।

খাঁটি CSS — কোনো JavaScript নেই?

সঠিক। প্রিভিউ টুলটি যে CSS এক্সপোর্ট করে একই CSS ব্যবহার করে।

আরও রঙ ও CSS জেনারেটর

শেড ও টিন্টরঙের হারমোনিকালার কনভার্টারCSS গ্রেডিয়েন্টবক্স শ্যাডোগ্লাসমরফিজমCSS বাটনস্পিনার

দৃশ্যমান কালার প্যালেট জেনারেটর ও মৌলিক গ্রেডিয়েন্ট জেনারেটর আছে Loona Image Tools; এই পরিবারটি CSS-ডেভেলপার-মানের সেট (বহু-ধাপের গ্রেডিয়েন্ট, হুবহু কোড আউটপুট)।

এই টুলটি আপনার নিজের ওয়েবসাইট বা ব্লগে যোগ করুন — এটি সম্পূর্ণ বিনামূল্যে, কোনো সাইন-আপ লাগে না, এবং সবসময় সর্বশেষ সংস্করণ দেখায়। নিচের কোডটি কপি করুন এবং আপনার পেজে যেখানে টুলটি দেখাতে চান সেখানে আটকান। এম্বেডের নিচে ছোট “Powered by Loona Automation” ক্রেডিট লাইনটি রাখলে এই টুলটিকে বিনামূল্যে রাখতে সাহায্য হয় — তবে আপনি এটি সাজাতে বা সরাতেও পারেন; টুলটি যেভাবেই হোক কাজ করে।
