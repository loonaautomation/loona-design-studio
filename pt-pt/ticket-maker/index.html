Criador de Bilhetes — Bilhetes de Eventos Gratuitos com Talão

Em resumo: o Criador de Bilhetes desenha bilhetes de eventos clássicos — secção principal com evento, data e lugar, mais uma margem de talão tracejada com "Admit One" — num tamanho de impressão largo para espetáculos escolares, rifas e funções.

Um bilhete impresso faz uma peça da escola parecer teatro e uma rifa parecer oficial. Numere os lugares editando cópias, ou mantenha um design principal para a porta.

Clique num bloco para o selecionar, arraste para mover, arraste o canto inferior direito para redimensionar. Camadas: use Enviar para trás / Trazer para a frente.

Privado por design: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. Os seus dados, fotografias e designs nunca são carregados para um servidor, nunca são guardados e nunca são vistos por nós - feche o separador e tudo desaparece.

Como usar o Criador de Bilhetes

  1. Escolha um tamanho e um modelo inicial — cada modelo é totalmente editável, nada está bloqueado.
  2. Clique em qualquer bloco de texto, forma ou fotografia para o editar: arraste para mover, arraste o canto para redimensionar, reestilize no editor sob o canvas.
  3. Adicione os seus próprios blocos de fotografia e fundo, organize as camadas com Enviar para trás / Trazer para a frente.
  4. Transfira o PNG no tamanho exato que escolheu, ou use Imprimir / Guardar como PDF para cópias em papel.

Como funciona

A linha dourada marca o talão destacável; a secção direita compacta repete o número do lugar, como fazem os bilhetes reais. Para tiragens numeradas, exporte o design uma vez e adicione números no modo de folheto da sua impressora, ou edite o texto do lugar por cópia. Esta página funciona com o editor de tela partilhado da Loona: o seu design é uma pilha de blocos de texto, formas e fotografias renderizados no tamanho exato de píxeis escolhido, por isso as exportações estão prontas para impressão e plataformas. Os blocos são mantidos dentro da tela e as camadas podem ser reordenadas. Tudo acontece no seu navegador — as fotografias nunca são carregadas.

Exemplo resolvido

Uma escola imprime 200 bilhetes de peça a partir deste design. Os pais guardam os talões como recordação — a noite já parece especial à porta.

Perguntas Frequentes

Como faço muitos números de lugar diferentes?

Edite os dois blocos de texto do lugar (principal e talão) por cópia, ou imprima o original e carimbe os números — para tiragens à escala escolar, editar alguns intervalos é o mais rápido.

Que papel devo usar?

Papel espesso ou cartolina, impresso a 100%. O design de 1500 × 550 imprime com cerca de 18 cm de largura.

Posso fazer bilhetes de rifa?

Sim — mude o texto do evento para a sua rifa e o lugar para um número de bilhete.

É gratuito?

Sim — gratuito, privado, sem marca de água.
