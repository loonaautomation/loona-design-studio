Gerador de Gradientes em Malha — Fundos com Gradiente Aurora / Blob em CSS

Em resumo: o Gerador de Gradientes em Malha sobrepõe quatro blobs suaves de radial-gradient sobre uma cor base — o visual aurora dos fundos das apps modernas — e exporta-o como CSS puro, sem ficheiros de imagem.

Os gradientes em malha fazem as páginas lisas parecerem vivas, mas escrever à mão quatro radial-gradients em camadas é uma miséria. Arraste os blobs aqui, copie duas linhas de CSS, feito.

Vários gradientes radiais suaves ("blobs") em camadas sobre uma cor base. Mova cada blob, redimensione o seu brilho, recolora-o.

Privado por design: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. Os seus dados, fotografias e designs nunca são carregados para um servidor, nunca são guardados e nunca são vistos por nós - feche o separador e tudo desaparece.

Como usar o Gerador de Gradientes em Malha

  1. Recolora a base — ela aparece onde os blobs se desvanecem.
  2. Para cada blob: escolha a sua cor, posição (x/y) e tamanho do brilho.
  3. Copie o CSS. A linha background-color pinta a base; background-image empilha os blobs.

Como funciona

Cada blob é um radial-gradient posicionado por percentagem com uma queda transparente; empilhá-los sobre uma base sólida produz a malha. Como é CSS puro, o fundo escala para qualquer ecrã com peso de imagem zero.

Exemplo resolvido

A secção principal de um site de portefólio passa de escura e simples para uma aurora verde-azulada e dourada que ecoa o logótipo do proprietário — duas linhas de CSS, sem transferências de imagens.

Perguntas Frequentes

Malha ou gradiente normal?

Um gradiente linear mistura-se ao longo de uma linha. Um gradiente em malha mistura vários conjuntos de cor em duas dimensões — mais suave, mais orgânico, mais "aurora".

Vai abrandar a minha página?

Não — é renderização CSS pura, sem ficheiros de imagem.

Posso adicionar mais blobs?

Quatro blobs cobrem a maioria dos designs. O padrão CSS exportado é fácil de alargar copiando um termo radial-gradient.

Funciona em telemóvel?

Sim — o posicionamento em percentagem torna-o totalmente responsivo.
