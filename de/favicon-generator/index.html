Favicon-Generator — favicon.ico & PNG-Symbol-Sets kostenlos erstellen

Kurz gesagt: der Favicon-Generator verwandelt einen Buchstaben, Ihre Initialen, ein Emoji — oder Ihr eigenes hochgeladenes Logo-Bild — in ein vollständiges Website-Symbol-Paket: ein echtes favicon.ico (16/32/48), PNGs in 16, 32, 48, 180, 192 und 512, ein site.webmanifest und das exakte HTML-Snippet, um sie zu installieren, alles in einer ZIP-Datei.

Jede Website braucht ein Favicon, und eines zu machen bedeutet normalerweise, mit einem Bildeditor bei 16 Pixeln zu kämpfen. Wählen Sie Ihr Zeichen, laden Sie das Paket herunter, fügen Sie einen Snippet ein — fertig in zwei Minuten.

Privat per Design: Alles in diesem Tool geschieht zu 100% in Ihrem Browser mit JavaScript. Ihre Daten, Fotos und Designs werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab und alles ist weg.

So verwenden Sie den Favicon-Generator

  1. Wählen Sie Ihren Startpunkt: Tippen Sie einen Buchstaben, Initialen oder ein Emoji ein — oder laden Sie Ihr Logo/Foto hoch und es wird mittig in die Symbolform geschnitten.
  2. Wählen Sie eine Form (abgerundetes Quadrat, Quadrat, Kreis) und, für den Buchstaben-Modus, die Hintergrund- und Buchstabenfarben. Die Vorschau aktualisiert sich live bei 256 Pixeln.
  3. Laden Sie das VOLLE PAKET (.zip) herunter: favicon.ico, sechs PNG-Größen, site.webmanifest und head-snippet.html.
  4. Entpacken Sie in Ihr Website-Stammverzeichnis und fügen Sie den Snippet in das Head Ihrer Seite ein . Browser finden favicon.ico automatisch.

So funktioniert es

Die .ICO-Datei wird Byte für Byte in Ihrem Browser gebaut: ein ICONDIR-Header, gefolgt von einem Eintrag pro Größe, jeder mit einem PNG — das moderne, PNG-komprimierte ICO-Format, das jeder aktuelle Browser akzeptiert. Jedes PNG wird frisch in seiner exakten Pixelgröße gezeichnet, und die ZIP-Datei wird lokal von Loonas eigenem ZIP-Writer mit korrekten Prüfsummen zusammengebaut. Der Upload-Modus schneidet Ihr Bild in jeder Größe Cover-mittig in die Symbolform.

Durchgerechnetes Beispiel

Eine Schülerin, die ihre erste Portfolio-Website startet, behält ihr Adler-Logo, lädt es hier hoch, lädt das Paket herunter, fügt den Snippet ein — und ihr Browser-Tab trägt endlich ihr eigenes Zeichen statt des Standard-Globus.

Häufig gestellte Fragen

Was ist ein Favicon?

Das kleine Symbol auf einem Browser-Tab, in Lesezeichen und auf Startbildschirmen. Websites verwenden ein favicon.ico im Stammverzeichnis plus PNG-Größen für Telefone und Manifeste — das Paket enthält alle.

Wie installiere ich das Paket?

Entpacken Sie es in das Stammverzeichnis Ihrer Website und fügen Sie den Inhalt von head-snippet.html in den Head Ihrer Seite ein. Das ist die ganze Aufgabe.

Kann ich mein eigenes Logo-Bild verwenden?

Ja — wählen Sie „Hochgeladenes Bild / Logo“. Es wird in jeder Größe mittig auf ein Quadrat geschnitten, sodass ein quadratisches Logo am besten funktioniert.

Ist das .ICO ein echtes ICO oder ein umbenanntes PNG?

Ein echtes ICO: eine korrekte ICONDIR-Struktur mit drei PNG-codierten Größen (16, 32 und 48) — das Format, das Browser erwarten, verifiziert durch unsere automatisierten Tests.

Wird mein Bild hochgeladen?

Nie — das ganze Paket wird auf Ihrem Gerät generiert.
