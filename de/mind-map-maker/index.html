Mindmap-Ersteller — Kostenloses Online-Mindmapping mit Auto-Layout

Kurz gesagt: der Mindmap-Ersteller wachsen lässt ein ordentliches Diagramm aus einer zentralen Idee: Klicken Sie einen Knoten, fügen Sie Kinder und Geschwister mit Buttons oder Tastatur hinzu, und der Baum legt sich automatisch neu — dann exportieren Sie ein PNG oder speichern die Map als JSON, um später fortzufahren.

Stundenplanung, Essay-Struktur, Projekt-Aufschlüsselungen, Wiederholungs-Notizen — eine Mindmap verwandelt ein verwickeltes Thema in ein Bild. Beginnen Sie mit der großen Idee in der Mitte und verzweigen Sie nach außen; das Tool hält alles ordentlich, während Sie denken.

Klicken Sie auf einen Knoten, um ihn auszuwählen. Ziehen Sie leeren Raum, um zu schwenken. Das Layout räumt sich nach jeder Änderung automatisch auf.

Privat per Design: Alles in diesem Tool geschieht zu 100% in Ihrem Browser mit JavaScript. Ihre Daten, Fotos und Designs werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab und alles ist weg.

So verwenden Sie den Mindmap-Ersteller

  1. Klicken Sie auf den zentralen Knoten und tippen Sie Ihre Hauptidee in das Textfeld Ausgewählter Knoten ein.
  2. Drücken Sie Kind hinzufügen (oder die Tab-Taste), um vom ausgewählten Knoten zu verzweigen; drücken Sie Geschwister hinzufügen (oder Eingabe) für einen Knoten auf derselben Ebene.
  3. Klicken Sie auf einen Knoten, um seinen Text zu bearbeiten. Ziehen Sie leeren Raum, um zu schwenken, und verwenden Sie Zoomen oder Anpassen, um die ganze Map einzurahmen.
  4. Laden Sie ein PNG zum Teilen oder Drucken herunter, oder Speichern Sie als JSON und laden Sie es später zurück, um weiter zu bearbeiten.

So funktioniert es

Die Map ist ein Baum von Knoten. Ein ordentlicher Layout-Algorithmus misst jeden Zweig: Ein Zweig ist so hoch wie seine Kinder, gestapelt mit gleichmäßigem Abstand, Eltern sitzen zentriert neben ihren Kindern, und jede Ebene bekommt ihre eigene Spalte — sodass Boxen nie überlappen, wie der Baum auch wächst. Kanten werden als weiche Kurven gezeichnet. Der Export rendert dasselbe Layout auf eine frische Leinwand, exakt auf die Map bemessen, und JSON Speichern/Laden speichert den ganzen Baum als einfachen Text, den Sie überall aufbewahren können.

Durchgerechnetes Beispiel

Ein Lehrer, der eine Naturwissenschafts-Einheit plant, beginnt mit „The Water Cycle“ in der Mitte, fügt die Kinder Verdunstung, Kondensation, Niederschlag und Sammlung hinzu und gibt jedem zwei Detail-Knoten. Das fertige PNG wird zum Klassen-Handout, und die JSON-Datei lässt ihn dieselbe Map im nächsten Semester erweitern.

Häufig gestellte Fragen

Wie füge ich Knoten schnell hinzu?

Wählen Sie einen Knoten aus und drücken Sie Tab für ein Kind oder Eingabe für ein Geschwister. Die Buttons über der Leinwand tun dasselbe auf Touchscreens.

Kann ich eine Mindmap speichern und später fortfahren?

Ja — Als JSON speichern lädt die ganze Map herunter. Verwenden Sie die Laden-Auswahl, um sie erneut zu öffnen und weiter zu bearbeiten.

Bleiben große Maps lesbar?

Das Layout überlappt nie Boxen, und Sie können schwenken, zoomen und Anpassen verwenden, um alles zu sehen. Der PNG-Export ist auf die volle Map bemessen, sodass nichts abgeschnitten wird.

Ist meine Mindmap privat?

Vollständig — die Map lebt in Ihrem Browser. Nichts wird von uns hochgeladen oder gespeichert.

Kann ich die Farben ändern?

Ja — fünf Themen (Blaugrün & Gold, Ocean, Sunset, Grape und Mono) gestalten die ganze Map sofort neu.
