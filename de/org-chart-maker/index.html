Organigramm-Ersteller — Kostenlose Organigramme aus Text

Kurz gesagt: der Organigramm-Ersteller verwandelt eine einfache eingerückte Liste — eine Rolle pro Zeile, Kinder unter ihrem Manager eingerückt — in ein ordentliches Organigramm mit Boxen, zentriert über ihren Teams, und exportiert es in voller Auflösung.

Organigramme Kasten für Kasten zu zeichnen ist langsam, und sie brechen bei jeder Umstrukturierung. Die Hierarchie als Text zu tippen ist schnell, und das Layout — wer über wem sitzt — wird für Sie berechnet, wie breit der Baum auch wächst.

Privat per Design: Alles in diesem Tool geschieht zu 100% in Ihrem Browser mit JavaScript. Ihre Daten, Fotos und Designs werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab und alles ist weg.

So verwenden Sie den Organigramm-Ersteller

  1. Bearbeiten Sie den Text: Die erste Zeile ist die oberste Rolle. Rücken Sie jede Zeile um zwei Leerzeichen (oder einen Tabulator) für jede Ebene unter ihrem Manager ein.
  2. Beobachten Sie, wie das Diagramm sich sofort neu aufbaut — Manager werden automatisch über ihrem ganzen Team zentriert.
  3. Korrigieren Sie Namen und Struktur im Text, bis das Diagramm exakt richtig liest.
  4. Laden Sie das PNG herunter — es exportiert in der vollen natürlichen Größe des Diagramms, nie gequetscht.

So funktioniert es

Das Layout ist ein Ordentlich-Baum-Algorithmus: Jeder Teilbaum ist so breit wie seine Kinder nebeneinander, und jeder Elternteil ist über seinem Teilbaum zentriert. Verbinder-Winkel fallen von einem Elternteil zu einer gemeinsamen Schiene über seinen Kindern. Weil die Breite aus dem Baum selbst berechnet wird, sind Exporte auf das echte Diagramm bemessen — große Organisationen bekommen einfach ein breiteres, immer noch scharfes PNG.

Durchgerechnetes Beispiel

Ein Schulleiter tippt die Personalstruktur in fünf Minuten ein — Schulleiter, stellvertretender Schulleiter, zwei Abteilungsleiter, Lehrer und Hilfspersonal — und das Diagramm kommt direkt in den Schulprospekt.

Häufig gestellte Fragen

Wie zeige ich zwei Personen auf derselben Ebene?

Geben Sie ihnen dieselbe Einrückung unter derselben Manager-Zeile.

Was, wenn meine Text-Einrückung falsch ist?

Die Regel ist einfach: Eine Zeile gehört zur nächsten Zeile über ihr mit weniger Einrückung. Halten Sie Einrückungen konsistent (zwei Leerzeichen pro Ebene) und der Baum baut sich selbst.

Kann das Diagramm sehr breit sein?

Ja — breite Bäume exportieren als breite PNGs in voller Auflösung. Die Vorschau auf dem Bildschirm skaliert herunter, um zu passen, der Download tut es nie.

Sind meine Personaldaten privat?

Vollständig — der Text wird nur in Ihrem Browser zerlegt.
