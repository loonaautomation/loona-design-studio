เครื่องมือสร้างแบนเนอร์ — แบนเนอร์เว็บ ปก & ส่วนหัวฟรี

กล่าวโดยสรุป: เครื่องมือสร้างแบนเนอร์ออกแบบแบนเนอร์เว็บที่ขนาดมาตรฐานที่แม่นยำ — ลีดเดอร์บอร์ด 728×90, สี่เหลี่ยมผืนผ้ากลาง 300×250, ตึกระฟ้ากว้าง 160×600, ปก Facebook และส่วนหัว X (Twitter) — จากแม่แบบที่แก้ไขได้

ทุกแพลตฟอร์มต้องการขนาดแบนเนอร์ที่ต่างกัน และการปรับขนาดด้วยมือเสียเวลาหนึ่งชั่วโมง ที่นี่ขนาดเป็นค่าตั้งต้น: ออกแบบครั้งเดียวต่อขนาดโดยแม่แบบทำงานเค้าโครงให้

คลิกบล็อกเพื่อเลือกมัน ลากเพื่อย้าย ลากมุมล่างขวาเพื่อปรับขนาด ชั้น: ใช้ ส่งไปด้านหลัง / นำมาด้านหน้า

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้นในเบราว์เซอร์ของคุณ 100% ด้วย JavaScript ข้อมูล ภาพถ่าย และงานออกแบบของคุณไม่เคยถูกอัปโหลดไปเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเราเห็น - ปิดแท็บและทุกอย่างก็หายไป

วิธีใช้เครื่องมือสร้างแบนเนอร์

  1. เลือกขนาดและแม่แบบเริ่มต้น — ทุกแม่แบบแก้ไขได้ทั้งหมด ไม่มีอะไรถูกล็อก
  2. คลิกบล็อกข้อความ รูปร่าง หรือภาพถ่ายใดก็ได้เพื่อแก้ไขมัน: ลากเพื่อย้าย ลากมุมเพื่อปรับขนาด จัดรูปแบบใหม่ในโปรแกรมแก้ไขใต้แคนวาส
  3. เพิ่มบล็อกภาพถ่ายและพื้นหลังของคุณเอง จัดเรียงชั้นด้วย ส่งไปด้านหลัง / นำมาด้านหน้า
  4. ดาวน์โหลด PNG ที่ขนาดที่คุณเลือกไว้พอดี หรือใช้ พิมพ์ / บันทึกเป็น PDF สำหรับสำเนากระดาษ

วิธีการทำงาน

ขนาดคือมิติพิกเซลของแพลตฟอร์มเอง การอัปโหลดจึงไม่เคยถูกตัดหรือยืดโดยเว็บไซต์ที่คุณโพสต์ ตึกระฟ้าถูกแก้ไขที่ความกว้างสองเท่าเพื่อการลากที่สะดวกและส่งออกที่ขนาดใช้งานของมัน — ตั้งเมนูขนาดก่อนดาวน์โหลด 160 × 600 ที่แม่นยำโดยการขยาย PNG ในเครื่องมือภาพใดก็ได้ หรือออกแบบโดยตรง: เค้าโครงเป็นสัดส่วน หน้านี้ทำงานบนโปรแกรมแก้ไขแคนวาสร่วมของ Loona: งานออกแบบของคุณคือกองซ้อนของบล็อกข้อความ รูปร่าง และภาพถ่าย ที่แสดงผลที่ขนาดพิกเซลที่เลือกไว้พอดี การส่งออกจึงพร้อมสำหรับงานพิมพ์และแพลตฟอร์ม บล็อกถูกจำกัดไว้ภายในแคนวาสและชั้นสามารถจัดลำดับใหม่ได้ ทุกอย่างเกิดขึ้นในเบราว์เซอร์ของคุณ — ภาพถ่ายไม่เคยถูกอัปโหลด

ตัวอย่างที่ทำแล้ว

ครูสอนพิเศษสร้างภาพปก Facebook และส่วนหัว X จากแม่แบบ Minimal เดียวกันในสิบนาที ในที่สุดโปรไฟล์ทั้งสองก็เข้ากัน

คำถามที่พบบ่อย

รวมขนาดอะไรบ้าง?

ลีดเดอร์บอร์ด 728×90, สี่เหลี่ยมผืนผ้ากลาง 300×250, ขนาดใช้งานตึกระฟ้ากว้าง, ปก Facebook 1640×924 และส่วนหัว X 1500×500 — ชุดแบนเนอร์เว็บมาตรฐาน

ทำไมตึกระฟ้าเป็นขนาดใช้งาน?

ที่ความกว้างจริง 160 px บล็อกข้อความลากให้แม่นยำได้ยาก โปรแกรมแก้ไขทำงานที่มาตราส่วนที่สะดวกโดยมีสัดส่วนเหมือนกัน

ฉันใช้แบนเนอร์สำหรับเว็บไซต์ของฉันได้ไหม?

ใช่ — ลีดเดอร์บอร์ดและสี่เหลี่ยมผืนผ้าคือขนาดแบนเนอร์โฆษณา/เนื้อหาเว็คคลาสสิก

มันฟรีหรือไม่?

ใช่ — ฟรี เป็นส่วนตัว ไม่มีลายน้ำ

เครื่องมือสร้างแม่แบบเพิ่มเติม

เครื่องมือสร้างโปสเตอร์เครื่องมือสร้างใบปลิวเครื่องมือสร้างแบนเนอร์เครื่องมือสร้างอินโฟกราฟิกเครื่องมือสร้างนามบัตรเครื่องมือสร้างหัวจดหมายเครื่องมือสร้างเมนูเครื่องมือสร้างปกหนังสือเครื่องมือสร้างปกอัลบั้มภาพขนาดย่อ YouTubeเครื่องมือสร้างคำคมเครื่องมือสร้างปฏิทิน

ใบรับรองอยู่ใน Loona PDF Tools (เครื่องมือสร้างใบรับรอง) — สิ่งเหล่านี้เป็นเอกสาร จึงไม่ทำซ้ำไว้ที่นี่
