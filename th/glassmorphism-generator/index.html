เครื่องมือสร้าง Glassmorphism — การ์ด CSS กระจกฝ้า

กล่าวโดยสรุป: เครื่องมือสร้าง Glassmorphism ออกแบบแผงกระจกฝ้า — การเบลอฉากหลัง โทนสีโปร่งแสง การเพิ่มความอิ่มตัว และขอบเส้นผม — แสดงตัวอย่างเหนือการไล่สีจริงเพื่อให้คุณตัดสินเอฟเฟกต์อย่างซื่อตรง

Glassmorphism ทำงานได้เฉพาะบนสีเท่านั้น: แถบเลื่อนความเบลอบนหน้าสีขาวไม่สอนอะไรเลย ตัวอย่างนี้ลอยการ์ดของคุณบนการไล่สีที่สดใส เหมือนกับที่มันจะอยู่ในงานออกแบบจริง

การ์ดกระจกฝ้า
เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้นในเบราว์เซอร์ของคุณ 100% ด้วย JavaScript ข้อมูล ภาพถ่าย และงานออกแบบของคุณไม่เคยถูกอัปโหลดไปเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเราเห็น - ปิดแท็บและทุกอย่างก็หายไป

วิธีใช้เครื่องมือสร้าง Glassmorphism

  1. ปรับการเบลอก่อน — 10–16 px คือฝ้าคลาสสิก
  2. ตั้งความทึบแสงของโทนสีให้ต่ำ (15–30%) เพื่อให้พื้นหลังเรืองแสงทะลุผ่าน เพิ่มความอิ่มตัวเพื่อให้สีฉ่ำหลังการเบลอ
  3. คัดลอก CSS ของ .glass-card บรรทัด -webkit- รวมอยู่ด้วยสำหรับ Safari

วิธีการทำงาน

backdrop-filter เบลออะไรก็ตามที่ระบายไว้หลังองค์ประกอบ ไม่ใช่องค์ประกอบเอง — นั่นคือเหตุผลที่โทนสีต้องคงโปร่งแสง การเพิ่มความอิ่มตัวชดเชยสีเทาที่การเบลอเพิ่ม ขอบสีขาวกึ่ง 1 px และเงานุ่มทำให้ภาพลวงตา "แผ่นกระจก" สมบูรณ์

ตัวอย่างที่ทำแล้ว

การ์ดสถิติของแดชบอร์ดกลายเป็นแบบฝ้าบนการไล่สีของแบรนด์ — ข้อมูลเดิม แต่จู่ ๆ ก็ดูเป็นผลิตภัณฑ์ปี 2026 CSS มาจากที่นี่ในการคัดลอกครั้งเดียว

คำถามที่พบบ่อย

ทำไมกระจกของฉันดูเป็นสีเทา?

เพิ่มแถบเลื่อนความอิ่มตัวและลดความทึบแสงของโทนสี — การเบลอเฉลี่ยสีไปทางเทา และการควบคุมสองอย่างนี้ต่อต้านมัน

มันใช้ได้ในเบราว์เซอร์ทั้งหมดหรือไม่?

backdrop-filter รองรับในเบราว์เซอร์สมัยใหม่ทุกตัว ผลลัพธ์รวมคำนำหน้า -webkit- สำหรับ Safari บนเบราว์เซอร์เก่ามาก การ์ดเพียงปรากฏเป็นแผงโปร่งแสง

กระจกควรอยู่บนพื้นหลังแบบใด?

พื้นหลังที่มีสีสันและค่อนข้างยุ่งแสดงเอฟเฟกต์ฝ้าได้ดีที่สุด: การไล่สี ภาพถ่าย การไล่สีแบบตาข่าย (สร้างด้วยเครื่องมือสร้างการไล่สีแบบตาข่ายของเรา)

เอฟเฟกต์มีต้นทุนสูงหรือไม่?

พื้นที่เบลอขนาดใหญ่ใช้ GPU บ้าง ให้แผงกระจกมีขนาดพอเหมาะบนโทรศัพท์ระดับล่าง

เครื่องมือสร้างสี & CSS เพิ่มเติม

เฉดสี & โทนสีอ่อนความกลมกลืนของสีเครื่องมือแปลงสีการไล่สี CSSเงากล่องGlassmorphismปุ่ม CSSSpinner

เครื่องมือสร้างพาเลตต์สีภาพและเครื่องมือสร้างการไล่สีพื้นฐานอยู่ใน Loona Image Tools; กลุ่มนี้คือชุดระดับนักพัฒนา CSS (การไล่สีหลายจุดหยุด ผลลัพธ์โค้ดที่แม่นยำ)

ฝังเครื่องมือนี้บนเว็บไซต์ของคุณ — ฟรี

เพิ่มเครื่องมือนี้ในเว็บไซต์หรือบล็อกของคุณเอง — ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครใช้งาน และแสดงเวอร์ชันล่าสุดเสมอ คัดลอกโค้ดด้านล่างและวางลงในหน้าของคุณตรงตำแหน่งที่ต้องการให้เครื่องมือปรากฏ การคงบรรทัดเครดิตเล็ก ๆ “ขับเคลื่อนโดย Loona Automation” ไว้ใต้ตัวฝังช่วยรักษาให้เครื่องมือนี้ฟรีต่อไป — แต่คุณมีอิสระที่จะจัดรูปแบบหรือลบมันออก เครื่องมือทำงานได้ไม่ว่าอย่างไร
