Aliceblue — #F0F8FF

กล่าวโดยสรุป: Aliceblue คือ #F0F8FF (RGB 240, 248, 255) — สีที่เย็นและสว่าง ใกล้สีขาว / พาสเทล พร้อมโปรไฟล์การคำนวณฉบับสมบูรณ์ สเกลเฉดสี และชุดสีที่กลมกลืน

หนึ่งใน 148 สีที่มีชื่อซึ่ง CSS กำหนดไว้ — หน้านี้คือโปรไฟล์การใช้งานฉบับสมบูรณ์ของสีนี้: ทุกรูปแบบ คอนทราสต์ WCAG สเกลเฉดสี 50–950 และชุดสีที่กลมกลืนจากการคำนวณ ทั้งหมดพร้อมคัดลอก

ใช้ Aliceblue ให้ได้ผลดี

Aliceblue อยู่ในกลุ่มใกล้สีขาว / พาสเทล ที่มีความสว่าง 97% — เป็นสีที่สว่าง, สดใส และเย็น เมื่อใช้เป็นพื้นหลัง ข้อความสีดำจะอ่านง่ายที่สุดบนพื้นหลังนี้ (คอนทราสต์ 19.58:1) สีคู่ตรงข้าม (#FFF7F0) เป็นคู่ที่ให้พลังสูงสำหรับปุ่มเรียกร้องให้ดำเนินการและจุดเน้น ส่วนสีข้างเคียง (#F0FFFE, #F0F0FF) ให้การไล่สีที่เรียบสงบในกลุ่มสีเดียวกัน สำหรับงานพิมพ์ ให้เริ่มจากค่า CMYK ด้านบนและพิมพ์ทดสอบก่อน — บนหน้าจอ Aliceblue เป็นสี sRGB และเฉดสีหน้าจอที่เข้มข้นอาจเพี้ยนได้เมื่อพิมพ์

คำถามที่พบบ่อย

รหัสเลขฐานสิบหกของ Aliceblue คืออะไร?

#F0F8FF — สี CSS ที่มีชื่อว่า “aliceblue” ค่า RGB ของสีนี้คือ (240, 248, 255)

Aliceblue เหมาะสำหรับข้อความหรือพื้นหลัง?

เมื่อใช้เป็นพื้นหลัง ข้อความสีดำจะอ่านง่ายที่สุดบนพื้นหลังนี้ (19.58:1) เมื่อใช้เป็นข้อความบนพื้นหลังสีขาว สีนี้ได้ 1.07:1 — ไม่เพียงพอสำหรับข้อความเนื้อหาตามเกณฑ์ AA ให้ใช้สำหรับหัวข้อ ข้อความขนาดใหญ่ หรือจุดเน้น

สีอะไรเข้ากับ Aliceblue?

สีคู่ตรงข้าม #FFF7F0 สำหรับคอนทราสต์ สีข้างเคียง #F0FFFE และ #F0F0FF สำหรับชุดสีที่เรียบสงบ และสเกลเฉดสี 50–950 ด้านบนสำหรับงานดีไซน์โทนสีเดียว

Aliceblue ในระบบ CMYK สำหรับงานพิมพ์คืออะไร?

C6 M3 Y0 K0 การแปลง CMYK จากสีหน้าจอเป็นเพียงจุดเริ่มต้น — ควรพิมพ์ทดสอบก่อนพิมพ์จำนวนมากเสมอ
