เครื่องมือสร้าง Favicon — สร้าง favicon.ico & ชุดไอคอน PNG ฟรี

กล่าวโดยสรุป: เครื่องมือสร้าง Favicon เปลี่ยนตัวอักษรหนึ่งตัว ตัวอักษรย่อของคุณ อิโมจิ — หรือภาพโลโก้ที่คุณอัปโหลดเอง — เป็นแพ็กไอคอนเว็บไซต์ที่สมบูรณ์: favicon.ico จริง (16/32/48) PNG ที่ 16, 32, 48, 180, 192 และ 512 ไฟล์ site.webmanifest และส่วนย่อย HTML ที่แม่นยำสำหรับติดตั้งพวกมัน ทั้งหมดใน ZIP เดียว

ทุกเว็บไซต์ต้องการ favicon และการทำอันหนึ่งมักหมายถึงการต่อสู้กับโปรแกรมแก้ไขภาพที่ 16 พิกเซล เลือกเครื่องหมายของคุณ ดาวน์โหลดแพ็ก วางโค้ดตัวอย่างหนึ่งชุด — เสร็จในสองนาที

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้นในเบราว์เซอร์ของคุณ 100% ด้วย JavaScript ข้อมูล ภาพถ่าย และงานออกแบบของคุณไม่เคยถูกอัปโหลดไปเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเราเห็น - ปิดแท็บและทุกอย่างก็หายไป

วิธีใช้เครื่องมือสร้าง Favicon

  1. เลือกจุดเริ่มต้นของคุณ: พิมพ์ตัวอักษร ตัวอักษรย่อ หรืออิโมจิ — หรืออัปโหลดโลโก้/ภาพถ่ายของคุณและมันจะถูกครอบกลางเป็นรูปร่างไอคอน
  2. เลือกรูปทรง (สี่เหลี่ยมมุมโค้ง สี่เหลี่ยมจัตุรัส วงกลม) และสำหรับโหมดตัวอักษร สีพื้นหลังและสีตัวอักษร ตัวอย่างอัปเดตสดที่ 256 พิกเซล
  3. ดาวน์โหลดแพ็กเต็ม (.zip): favicon.ico, ขนาด PNG หกขนาด, site.webmanifest และ head-snippet.html
  4. แตกไฟล์ลงในรากเว็บไซต์ของคุณและวางส่วนย่อยลงในหน้าของคุณ . เบราว์เซอร์ค้นหา favicon.ico โดยอัตโนมัติ

วิธีการทำงาน

ไฟล์ .ICO ถูกสร้างทีละไบต์ในเบราว์เซอร์ของคุณ: ส่วนหัว ICONDIR ตามด้วยหนึ่งรายการต่อขนาด แต่ละรายการถือ PNG หนึ่งภาพ — รูปแบบ ICO ที่บีบอัดด้วย PNG สมัยใหม่ที่เบราว์เซอร์ปัจจุบันทุกตัวรองรับ PNG แต่ละภาพถูกวาดใหม่ที่ขนาดพิกเซลที่แม่นยำ และ ZIP ถูกประกอบในเครื่องโดยโปรแกรมเขียน ZIP ของ Loona เองพร้อมเช็กซัมที่ถูกต้อง โหมดอัปโหลดตัดครอบภาพของคุณเป็นรูปทรงไอคอนในทุกขนาด

ตัวอย่างที่ทำแล้ว

นักเรียนที่เปิดเว็บไซต์ผลงานแรกของเธอยังคงโลโก้อินทรีของเธอไว้ อัปโหลดมันที่นี่ ดาวน์โหลดแพ็ก วางโค้ดตัวอย่าง — และในที่สุดแท็บเบราว์เซอร์ของเธอก็มีเครื่องหมายของเธอเองแทนลูกโลกเริ่มต้น

คำถามที่พบบ่อย

favicon คืออะไร?

ไอคอนเล็กบนแท็บเบราว์เซอร์ ในบุ๊กมาร์ก และบนหน้าจอหลัก เว็บไซต์ใช้ favicon.ico ในรากบวกขนาด PNG สำหรับโทรศัพท์และไฟล์แสดงรายการ — แพ็กมีพวกมันทั้งหมด

ฉันติดตั้งแพ็กอย่างไร?

แตกไฟล์ลงในโฟลเดอร์รากของเว็บไซต์ของคุณและวางเนื้อหาของ head-snippet.html ลงในส่วนหัวของหน้าคุณ นั่นคืองานทั้งหมด

ฉันใช้ภาพโลโก้ของฉันเองได้ไหม?

ใช่ — เลือก "ภาพ / โลโก้ที่อัปโหลด" มันถูกตัดกลางเป็นสี่เหลี่ยมจัตุรัสในทุกขนาด โลโก้ที่ค่อนข้างเป็นสี่เหลี่ยมจึงใช้ได้ดีที่สุด

.ICO เป็น ICO จริงหรือ PNG ที่เปลี่ยนชื่อ?

ICO ของจริง: โครงสร้าง ICONDIR ที่ถูกต้องซึ่งบรรจุสามขนาดที่เข้ารหัสเป็น PNG (16, 32 และ 48) — รูปแบบที่เบราว์เซอร์คาดหวัง ผ่านการตรวจสอบโดยการทดสอบอัตโนมัติของเรา

รูปภาพของฉันถูกอัปโหลดหรือไม่?

ไม่เคย — แพ็กทั้งหมดถูกสร้างบนอุปกรณ์ของคุณ

เครื่องมืออวาตาร์ & ไอคอนเพิ่มเติม

เครื่องมือสร้าง Faviconเครื่องมือสร้างอวตารตัวอักษรย่อเครื่องมือสร้างอวาตาร์พิกเซลเครื่องมือสร้างโลโก้

ฝังเครื่องมือนี้บนเว็บไซต์ของคุณ — ฟรี

เพิ่มเครื่องมือนี้ในเว็บไซต์หรือบล็อกของคุณเอง — ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครใช้งาน และแสดงเวอร์ชันล่าสุดเสมอ คัดลอกโค้ดด้านล่างและวางลงในหน้าของคุณตรงตำแหน่งที่ต้องการให้เครื่องมือปรากฏ การคงบรรทัดเครดิตเล็ก ๆ “ขับเคลื่อนโดย Loona Automation” ไว้ใต้ตัวฝังช่วยรักษาให้เครื่องมือนี้ฟรีต่อไป — แต่คุณมีอิสระที่จะจัดรูปแบบหรือลบมันออก เครื่องมือทำงานได้ไม่ว่าอย่างไร
