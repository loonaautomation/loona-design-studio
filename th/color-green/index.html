Green — #008000

กล่าวโดยสรุป: Green คือ #008000 (RGB 0, 128, 0) — สีเขียวที่เป็นกลางโทนอบอุ่นและเข้ม พร้อมโปรไฟล์การคำนวณฉบับสมบูรณ์ สเกลเฉดสี และชุดสีที่กลมกลืน

หนึ่งใน 148 สีที่มีชื่อซึ่ง CSS กำหนดไว้ — หน้านี้คือโปรไฟล์การใช้งานฉบับสมบูรณ์ของสีนี้: ทุกรูปแบบ คอนทราสต์ WCAG สเกลเฉดสี 50–950 และชุดสีที่กลมกลืนจากการคำนวณ ทั้งหมดพร้อมคัดลอก

ใช้ Green ให้ได้ผลดี

Green อยู่ในกลุ่มสีเขียวที่มีความสว่าง 25% — เป็นสีที่เข้ม, สดใส และเป็นกลางโทนอบอุ่น เมื่อใช้เป็นพื้นหลัง ข้อความสีขาวจะอ่านง่ายที่สุดบนพื้นหลังนี้ (คอนทราสต์ 5.14:1) สีคู่ตรงข้าม (#800080) เป็นคู่ที่ให้พลังสูงสำหรับปุ่มเรียกร้องให้ดำเนินการและจุดเน้น ส่วนสีข้างเคียง (#408000, #008040) ให้การไล่สีที่เรียบสงบในกลุ่มสีเดียวกัน สำหรับงานพิมพ์ ให้เริ่มจากค่า CMYK ด้านบนและพิมพ์ทดสอบก่อน — บนหน้าจอ Green เป็นสี sRGB และเฉดสีหน้าจอที่เข้มข้นอาจเพี้ยนได้เมื่อพิมพ์

คำถามที่พบบ่อย

รหัสเลขฐานสิบหกของ Green คืออะไร?

#008000 — สี CSS ที่มีชื่อว่า “green” ค่า RGB ของสีนี้คือ (0, 128, 0)

Green เหมาะสำหรับข้อความหรือพื้นหลัง?

เมื่อใช้เป็นพื้นหลัง ข้อความสีขาวจะอ่านง่ายที่สุดบนพื้นหลังนี้ (5.14:1) เมื่อใช้เป็นข้อความบนพื้นหลังสีขาว สีนี้ได้ 5.14:1 — เพียงพอสำหรับข้อความขนาดปกติตามเกณฑ์ WCAG AA

สีอะไรเข้ากับ Green?

สีคู่ตรงข้าม #800080 สำหรับคอนทราสต์ สีข้างเคียง #408000 และ #008040 สำหรับชุดสีที่เรียบสงบ และสเกลเฉดสี 50–950 ด้านบนสำหรับงานดีไซน์โทนสีเดียว

Green ในระบบ CMYK สำหรับงานพิมพ์คืออะไร?

C100 M0 Y100 K50 การแปลง CMYK จากสีหน้าจอเป็นเพียงจุดเริ่มต้น — ควรพิมพ์ทดสอบก่อนพิมพ์จำนวนมากเสมอ
