Dark Slate Gray — #2F4F4F

กล่าวโดยสรุป: Dark Slate Gray คือ #2F4F4F (RGB 47, 79, 79) — สีฟ้า / เขียวอมฟ้า ที่เย็นและเข้ม พร้อมโปรไฟล์การคำนวณฉบับสมบูรณ์ สเกลเฉดสี และชุดสีที่กลมกลืน

หนึ่งใน 148 สีที่มีชื่อซึ่ง CSS กำหนดไว้ — หน้านี้คือโปรไฟล์การใช้งานฉบับสมบูรณ์ของสีนี้: ทุกรูปแบบ คอนทราสต์ WCAG สเกลเฉดสี 50–950 และชุดสีที่กลมกลืนจากการคำนวณ ทั้งหมดพร้อมคัดลอก

ใช้ Dark Slate Gray ให้ได้ผลดี

Dark Slate Gray อยู่ในกลุ่มสีฟ้า / เขียวอมฟ้า ที่มีความสว่าง 25% — เป็นสีที่เข้ม, หม่น และเย็น เมื่อใช้เป็นพื้นหลัง ข้อความสีขาวจะอ่านง่ายที่สุดบนพื้นหลังนี้ (คอนทราสต์ 8.93:1) สีคู่ตรงข้าม (#4F2F2F) เป็นคู่ที่ให้พลังสูงสำหรับปุ่มเรียกร้องให้ดำเนินการและจุดเน้น ส่วนสีข้างเคียง (#2F4F3F, #2F3F4F) ให้การไล่สีที่เรียบสงบในกลุ่มสีเดียวกัน สำหรับงานพิมพ์ ให้เริ่มจากค่า CMYK ด้านบนและพิมพ์ทดสอบก่อน — บนหน้าจอ Dark Slate Gray เป็นสี sRGB และเฉดสีหน้าจอที่เข้มข้นอาจเพี้ยนได้เมื่อพิมพ์

คำถามที่พบบ่อย

รหัสเลขฐานสิบหกของ Dark Slate Gray คืออะไร?

#2F4F4F — สี CSS ที่มีชื่อว่า “darkslategray” ค่า RGB ของสีนี้คือ (47, 79, 79)

Dark Slate Gray เหมาะสำหรับข้อความหรือพื้นหลัง?

เมื่อใช้เป็นพื้นหลัง ข้อความสีขาวจะอ่านง่ายที่สุดบนพื้นหลังนี้ (8.93:1) เมื่อใช้เป็นข้อความบนพื้นหลังสีขาว สีนี้ได้ 8.93:1 — เพียงพอสำหรับข้อความขนาดปกติตามเกณฑ์ WCAG AA

สีอะไรเข้ากับ Dark Slate Gray?

สีคู่ตรงข้าม #4F2F2F สำหรับคอนทราสต์ สีข้างเคียง #2F4F3F และ #2F3F4F สำหรับชุดสีที่เรียบสงบ และสเกลเฉดสี 50–950 ด้านบนสำหรับงานดีไซน์โทนสีเดียว

Dark Slate Gray ในระบบ CMYK สำหรับงานพิมพ์คืออะไร?

C41 M0 Y0 K69 การแปลง CMYK จากสีหน้าจอเป็นเพียงจุดเริ่มต้น — ควรพิมพ์ทดสอบก่อนพิมพ์จำนวนมากเสมอ
