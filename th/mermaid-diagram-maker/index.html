เครื่องมือสร้างแผนภาพ Mermaid — วางโค้ด Mermaid รับแผนภาพ

กล่าวโดยสรุป: เครื่องมือสร้างแผนภาพ Mermaid นี้แยกวิเคราะห์ชุดย่อยผังงานของไวยากรณ์ Mermaid — ทิศทาง graph โหนดที่มีป้ายในรูปทรง [ ], ( ), { } และ (( )) ลูกศรพร้อม |ป้าย| — และแสดงผลแผนภาพแบบชั้นที่คุณดาวน์โหลดเป็น PNG ได้ ตัวแยกวิเคราะห์ทำงานทั้งหมดในเบราว์เซอร์ของคุณ

นักพัฒนาและนักเขียนเชิงเทคนิคอธิบายแผนภาพเป็นข้อความ Mermaid ในเอกสารและแชท AI เมื่อคุณต้องการแค่ภาพ — สำหรับสไลด์ เอกสาร หรือการตรวจสอบอย่างรวดเร็ว — วางโค้ดที่นี่แทนการตั้งค่าชุดเครื่องมือทั้งหมด

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้นในเบราว์เซอร์ของคุณ 100% ด้วย JavaScript ข้อมูล ภาพถ่าย และงานออกแบบของคุณไม่เคยถูกอัปโหลดไปเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเราเห็น - ปิดแท็บและทุกอย่างก็หายไป

วิธีใช้เครื่องมือสร้างแผนภาพ Mermaid

  1. วางหรือเขียนโค้ดผังงาน Mermaid ในกล่อง เริ่มด้วย graph TD (บนลงล่าง) หรือ graph LR (ซ้ายไปขวา)
  2. ใช้รูปทรงที่รองรับ: A[Process], B(Rounded), C{Decision}, D((Circle)) — และการเชื่อมต่อ A --> B หรือ A -->|label| B
  3. แผนภาพแสดงผลสดด้วยเค้าโครงแบบชั้น บรรทัดใด ๆ ที่อยู่นอกชุดย่อยที่รองรับจะถูกรายงานใต้แคนวาส ไม่เคยถูกทิ้งอย่างเงียบ ๆ
  4. ดาวน์โหลด PNG ที่ขนาดธรรมชาติเต็มของแผนภาพ

วิธีการทำงาน

ตัวแยกวิเคราะห์ที่เขียนเองอ่านโทเค็นโหนดและการเชื่อมต่อทีละบรรทัด จากนั้นเค้าโครงแบบชั้นกำหนดความลึกให้แต่ละโหนดโดยการค้นหาแบบกว้างก่อนจากราก (โหนดที่ไม่มีลูกศรเข้า) และจัดแต่ละระดับตามลำดับ รองรับ: ส่วนหัว flowchart/graph (TD, TB, BT, LR, RL) รูปทรงโหนดที่ระบุในหน้านี้ ลูกศรทึบและมีป้าย และลิงก์ธรรมดา (---) ไม่รองรับ (โดยการออกแบบ และระบุอย่างซื่อตรง): แผนภาพลำดับ คลาส สถานะ และ gantt กราฟย่อย และคำสั่งจัดสไตล์ — บรรทัดเหล่านั้นถูกทำเครื่องหมายในบรรทัดสถานะแทนที่จะแสดงผลอย่างผิด ๆ

ตัวอย่างที่ทำแล้ว

แชท AI ให้โค้ด Mermaid สำหรับขั้นตอนการชำระเงินแก่นักพัฒนา เธอวางมันที่นี่ ตรวจสอบว่าสาขาการตัดสินใจแสดงผลตามที่ตั้งใจ และวางไฟล์ PNG ลงในเอกสารออกแบบของทีม

คำถามที่พบบ่อย

รองรับไวยากรณ์ Mermaid แบบใด?

ชุดย่อยผังงาน: graph/flowchart TD/TB/BT/LR/RL, โหนด A[..], A(..), A{..}, A((..)), A[[..]], การเชื่อมต่อ -->, ---, -., รูปแบบ ==> และ |ป้าย| แผนภาพลำดับ/คลาส/gantt ไม่ใช่ส่วนหนึ่งของตัวแสดงผลนี้ — หน้าจะบอกคุณเมื่อบรรทัดใดไม่รองรับ

ทำไมไม่ใช้ไลบรารี Mermaid เต็มรูปแบบ?

หน้านี้เขียนเองเพื่อให้อยู่ในตัวสมบูรณ์และรวดเร็วโดยไม่มีการพึ่งพาภายนอกเลย ครอบคลุมชุดย่อยผังงานที่คนส่วนใหญ่วาง ไลบรารี Mermaid.js เต็มรูปแบบครอบคลุมประเภทแผนภาพมากกว่า

เกิดอะไรขึ้นกับบรรทัดที่ไม่รองรับ?

พวกมันถูกเก็บรวบรวมและรายงานในบรรทัดสถานะใต้แคนวาส ("Line N: not in the supported subset") — ไม่เคยถูกละเลยอย่างเงียบ ๆ

โค้ดของฉันถูกอัปโหลดหรือไม่?

ไม่ — การแยกวิเคราะห์และการแสดงผลเกิดขึ้นในเบราว์เซอร์ของคุณ 100%
