مولّد أزرار CSS — صمّم الأزرار واحصل على الكود

باختصار: يصمم مولّد أزرار CSS زرًا كاملًا — خلفية ونص وحشو ونصف قطر زاوية وحد وغامق — ويكتب CSS إنتاجيًا يتضمن حالة تمرير أغمق تلقائية.

الأزرار هي العنصر الأكثر لمسًا في أي موقع والأكثر إزعاجًا في التنسيق بالتجربة والخطأ. صمّم زرك هنا مرة واحدة؛ لون التمرير مشتق لك حتى.

خاص بالتصميم: كل شيء في هذه الأداة يحدث 100% في متصفحك بـJavaScript. بياناتك وصورك وتصاميمك لا تُرفع أبدًا إلى خادم، لا تُخزَّن أبدًا ولا نراها أبدًا - أغلق التبويب فيختفي كل شيء.

كيفية استخدام مولّد أزرار CSS

  1. نسّق زر المعاينة: الألوان أولًا، ثم الحجم (الحشو والنص)، ثم الزوايا والحد.
  2. درجة التمرير هي خلفيتك مُعتمة بخطوة ثابتة — افحص أنها تبدو صحيحة بتمرير منطقة المعاينة في مشروعك الخاص.
  3. انسخ CSS وأعد تسمية .my-button إلى فئتك.

كيف يعمل

يُحسب لون التمرير بطرح كمية ثابتة من كل قناة RGB للخلفية (مثبتة عند الأسود)، قاعدة موثوقة "نفس الدرجة، أعمق". يُقسَّم الحشو إلى قيم عمودية وأفقية لأن الأزرار الرائعة أوسع مما هي طويلة.

مثال عملي

ينتقل زر التبرع في موقع خيري من الأزرق الافتراضي إلى زر علامة كبير بحواف ذهبية — صفحة التبرعات تطابق الملصقات أخيرًا.

الأسئلة الشائعة

لماذا التمرير أغمق، لا أفتح؟

يُقرأ التعتيم عند التمرير كـ"ضغط للأسفل" تحت نفس الضوء — الاتفاقية التي يتوقعها المستخدمون لا شعوريًا.

هل يمكنني صنع زر حبة؟

اضبط نصف قطر الزاوية إلى أقصاه (40) مع ارتفاع متواضع — حبة كاملة.

هل يمكنني صنع زر محيطي (شبحي)؟

اضبط عرض حد، ثم استخدم حيلة صفحة ظل الصندوق: اضبط الخلفية فعليًا إلى لون صفحتك والنص إلى لون العلامة — أو بدّل ببساطة قيمتي اللون في CSS المنسوخ.

هل CSS خالٍ من الأطر؟

نعم — CSS عادي، يعمل في أي مكان، دون تبعيات.
