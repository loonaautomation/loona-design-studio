Light Slate Gray — #778899

Стисло: Light Slate Gray — це #778899 (RGB 119, 136, 153) — холодний, середньотоновий синій колір із повним обчисленим профілем, шкалою відтінків і гармоніями.

Один із 148 іменованих кольорів, визначених у CSS, — ця сторінка є його повним робочим профілем: усі формати, контраст WCAG, шкала відтінків 50–950 і обчислені гармонії, усе готове до копіювання.

Як вдало використовувати Light Slate Gray

Light Slate Gray належить до родини синього зі світлотою 53% — середньотоновий, приглушений, холодний колір. Як фон, він найкраще поєднується з текстом кольору чорного (контраст 5.77:1). Його доповнення (#998877) — енергійний партнер для закликів до дії та акцентів; аналогічні сусіди (#779999, #777799) дають спокійні градієнти в межах однієї родини. Для друку почніть із наведених вище значень CMYK і зробіть пробний відбиток — на екрані Light Slate Gray є кольором sRGB, а насичені екранні відтінки під час друку можуть змінитися.

Поширені запитання

Який hex-код у Light Slate Gray?

#778899 — іменований колір CSS «lightslategray». Його RGB — (119, 136, 153).

Чи підходить Light Slate Gray для тексту або фону?

Як фон, на ньому найкраще читається текст кольору чорного (5.77:1). Як текст на тлі білого він досягає 3.64:1 — недостатньо для основного тексту за AA; використовуйте його для заголовків, великого тексту або акцентів.

Які кольори пасують до Light Slate Gray?

Його доповнення #998877 — для контрасту, аналогічні #779999 і #777799 — для спокійних поєднань, а шкала відтінків 50–950 вище — для монохромних дизайнів.

Який вигляд має Light Slate Gray у CMYK для друку?

C22 M11 Y0 K40. Перетворення кольорів екрана в CMYK — лише відправна точка: перед тиражем завжди робіть пробний друк.
