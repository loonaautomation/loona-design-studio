Sandybrown — #F4A460

Стисло: Sandybrown — це #F4A460 (RGB 244, 164, 96) — теплий, світлий помаранчевий колір із повним обчисленим профілем, шкалою відтінків і гармоніями.

Один із 148 іменованих кольорів, визначених у CSS, — ця сторінка є його повним робочим профілем: усі формати, контраст WCAG, шкала відтінків 50–950 і обчислені гармонії, усе готове до копіювання.

Як вдало використовувати Sandybrown

Sandybrown належить до родини помаранчевого зі світлотою 67% — світлий, яскравий, теплий колір. Як фон, він найкраще поєднується з текстом кольору чорного (контраст 10.33:1). Його доповнення (#60B0F4) — енергійний партнер для закликів до дії та акцентів; аналогічні сусіди (#F46066, #F4EE60) дають спокійні градієнти в межах однієї родини. Для друку почніть із наведених вище значень CMYK і зробіть пробний відбиток — на екрані Sandybrown є кольором sRGB, а насичені екранні відтінки під час друку можуть змінитися.

Поширені запитання

Який hex-код у Sandybrown?

#F4A460 — іменований колір CSS «sandybrown». Його RGB — (244, 164, 96).

Чи підходить Sandybrown для тексту або фону?

Як фон, на ньому найкраще читається текст кольору чорного (10.33:1). Як текст на тлі білого він досягає 2.03:1 — недостатньо для основного тексту за AA; використовуйте його для заголовків, великого тексту або акцентів.

Які кольори пасують до Sandybrown?

Його доповнення #60B0F4 — для контрасту, аналогічні #F46066 і #F4EE60 — для спокійних поєднань, а шкала відтінків 50–950 вище — для монохромних дизайнів.

Який вигляд має Sandybrown у CMYK для друку?

C0 M33 Y61 K4. Перетворення кольорів екрана в CMYK — лише відправна точка: перед тиражем завжди робіть пробний друк.
