Cadetblue — #5F9EA0

Стисло: Cadetblue — це #5F9EA0 (RGB 95, 158, 160) — холодний, середньотоновий ціановий / бірюзовий колір із повним обчисленим профілем, шкалою відтінків і гармоніями.

Як вдало використовувати Cadetblue

Cadetblue належить до родини ціанового / бірюзового зі світлотою 50% — середньотоновий, приглушений, холодний колір. Як фон, він найкраще поєднується з текстом кольору чорного (контраст 6.88:1). Його доповнення (#A0615F) — енергійний партнер для закликів до дії та акцентів; аналогічні сусіди (#5FA082, #5F7DA0) дають спокійні градієнти в межах однієї родини. Для друку почніть із наведених вище значень CMYK і зробіть пробний відбиток — на екрані Cadetblue є кольором sRGB, а насичені екранні відтінки під час друку можуть змінитися.

Поширені запитання

Який hex-код у Cadetblue?

#5F9EA0 — іменований колір CSS «cadetblue». Його RGB — (95, 158, 160).

Чи підходить Cadetblue для тексту або фону?

Як фон, на ньому найкраще читається текст кольору чорного (6.88:1). Як текст на тлі білого він досягає 3.05:1 — недостатньо для основного тексту за AA; використовуйте його для заголовків, великого тексту або акцентів.

Які кольори пасують до Cadetblue?

Його доповнення #A0615F — для контрасту, аналогічні #5FA082 і #5F7DA0 — для спокійних поєднань, а шкала відтінків 50–950 вище — для монохромних дизайнів.

Який вигляд має Cadetblue у CMYK для друку?

C41 M1 Y0 K37. Перетворення кольорів екрана в CMYK — лише відправна точка: перед тиражем завжди робіть пробний друк.
