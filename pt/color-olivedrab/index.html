Como usar bem Olivedrab

Olivedrab pertence à família do verde com uma luminosidade de 35% — uma cor escura, moderadamente saturada e neutra quente. Como fundo, combina melhor com texto em preto (contraste 5.52:1). O seu complementar (#46238E) é o parceiro de alta energia para chamadas para ação e elementos em destaque; os vizinhos análogos (#8E7B23, #358E23) dão gradientes tranquilos da mesma família. Para imprimir, parta dos valores CMYK acima e faça uma prova — no ecrã, Olivedrab é uma cor sRGB e os tons intensos podem variar na impressão.

Perguntas Frequentes

Qual é o código hexadecimal de Olivedrab?

#6B8E23 — a cor CSS com nome “olivedrab”. O seu RGB é (107, 142, 35).

Olivedrab é uma boa opção para texto ou fundos?

Como fundo, o texto em preto lê-se melhor sobre ele (5.52:1). Como texto sobre branco atinge 3.81:1 — não é suficiente para o texto principal em AA; use-o para títulos, texto grande ou destaques.

Que cores combinam com Olivedrab?

O seu complementar #46238E para contraste, os análogos #8E7B23 e #358E23 para combinações tranquilas, e a escala de tons 50–950 acima para designs monocromáticos.

Qual é Olivedrab em CMYK para impressão?

C25 M0 Y75 K44. As conversões CMYK das cores de ecrã são um ponto de partida — faça sempre uma prova antes de uma tiragem.
