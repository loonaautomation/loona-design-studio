Editor de Pixel Art — Grelha de Desenho de Sprites e Pixel Gratuita

Em resumo: o Editor de Pixel Art é uma verdadeira grelha de sprites — caneta, preenchimento e borracha em células de 12 × 12 a 32 × 32 — exportando PNG perfeitamente nítidos com transparência, o formato de que os projetos de jogos e web precisam.

Pixel art é desenhar com quadrados deliberados: sprites de jogos, ícones, avatares retrô, rascunhos de ponto de cruz. A grelha aqui mantém cada píxel exato, e as exportações escalam por células inteiras para que nada desfoca.

Privado por design: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. Os seus dados, fotografias e designs nunca são carregados para um servidor, nunca são guardados e nunca são vistos por nós - feche o separador e tudo desaparece.

Como usar o Editor de Pixel Art

  1. Escolha um tamanho de grelha — 16 × 16 é o sprite clássico. Mudar o tamanho inicia uma grelha nova.
  2. Escolha uma cor da paleta (ou uma personalizada) e desenhe com a Caneta. Arraste para pintar sequências de píxeis.
  3. Use Preencher para inundar uma área fechada, Borracha para devolver as células à transparência.
  4. Transferir: o PNG é transparente onde não desenhou, escalado por células inteiras para uma nitidez perfeita.

Como funciona

A arte é uma grelha de dados de células cor-ou-vazias. O preenchimento é o preenchimento de região standard baseado em pilha. As exportações renderizam cada célula como um quadrado exato no tamanho de célula escolhido, sem suavização, sobre um fundo transparente — prontas para motores de jogos e uso como ícones.

Exemplo resolvido

Uma aluna desenha um foguetão de 16 × 16 para o seu primeiro jogo. Exportado a 24 px por célula, o sprite entra no projeto nítido e transparente.

Perguntas Frequentes

Porque é que a exportação é transparente?

Sprites e ícones têm de ficar sobre outros fundos. As células vazias ficam vazias no PNG — desenhe primeiro uma cor de fundo se quiser uma.

Como mantenho os píxeis nítidos em todo o lado?

Escale sempre a pixel art por números inteiros (2×, 3×…). Os tamanhos de exportação aqui são múltiplos exatos das células.

Posso converter uma fotografia em pixel art?

Este editor é para desenhar à mão, célula a célula. Para trabalhos baseados em fotografias, essa conversão é uma família de ferramentas diferente.

A minha arte é guardada em algum lado?

Apenas no separador do seu navegador — transfira o PNG para o manter.
