Gerador de Neumorphism — Sombras Soft UI em CSS

Em resumo: o Gerador de Neumorphism cria o visual soft-UI — um cartão que parece pressionado a partir da própria página — calculando uma sombra mais escura e uma mais clara a partir de uma cor de superfície e colocando-as em cantos opostos.

Todo o segredo do neumorphism é que o cartão e o fundo partilham uma cor, iluminada de dois lados. Escolha a superfície; a ferramenta deriva os dois tons de sombra para que pertençam sempre um ao outro.

Como usar o Gerador de Neumorphism

  1. Escolha a cor da superfície — mantenha-a cinzento claro ou uma tonalidade pálida; branco puro e cores escuras não podem fazer neumorph.
  2. Ajuste a distância (a que distância fica a luz) e a desfocagem (quão suave o material parece).
  3. Copie o CSS e defina a MESMA cor do fundo da sua página — essa correspondência é o efeito.

Como funciona

A sombra escura é a cor da superfície escurecida por um passo fixo, a sombra clara clareada pelo mesmo passo, colocadas diagonalmente opostas — simulando uma fonte de luz. Como ambas derivam da superfície, a ilusão sobrevive a qualquer matiz.

Exemplo resolvido

Os controlos do leitor de uma app de música ganham um estilo soft-UI: o botão de reprodução e o cartão de volume parecem moldados na mesma superfície cinzenta.

Perguntas Frequentes

Porque é que as cores do cartão e da página têm de corresponder?

O efeito é uma ilusão de sombra sobre um material contínuo. Cores diferentes quebram o feitiço instantaneamente.

O neumorphism é acessível?

O seu contraste é inerentemente baixo — use-o para contentores decorativos e controlos grandes, nunca para texto corrido ou ações críticas.

Posso fazer uma versão "pressionada"?

Troque os sinais das duas sombras no CSS copiado (ou use sombras inset) para o visual esculpido.

Que cores funcionam melhor?

Cinzentos claros e tonalidades pálidas (família #e0e5ec). As cores saturadas perdem a suavidade.
