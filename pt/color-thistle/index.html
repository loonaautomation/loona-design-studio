Como usar bem Thistle

Thistle pertence à família do magenta / do rosa com uma luminosidade de 80% — uma cor clara, suave e fria. Como fundo, combina melhor com texto em preto (contraste 12.36:1). O seu complementar (#BFD8BF) é o parceiro de alta energia para chamadas para ação e elementos em destaque; os vizinhos análogos (#CCBFD8, #D8BFCC) dão gradientes tranquilos da mesma família. Para imprimir, parta dos valores CMYK acima e faça uma prova — no ecrã, Thistle é uma cor sRGB e os tons intensos podem variar na impressão.

Perguntas Frequentes

Qual é o código hexadecimal de Thistle?

#D8BFD8 — a cor CSS com nome “thistle”. O seu RGB é (216, 191, 216).

Thistle é uma boa opção para texto ou fundos?

Como fundo, o texto em preto lê-se melhor sobre ele (12.36:1). Como texto sobre branco atinge 1.70:1 — não é suficiente para o texto principal em AA; use-o para títulos, texto grande ou destaques.

Que cores combinam com Thistle?

O seu complementar #BFD8BF para contraste, os análogos #CCBFD8 e #D8BFCC para combinações tranquilas, e a escala de tons 50–950 acima para designs monocromáticos.

Qual é Thistle em CMYK para impressão?

C0 M12 Y0 K15. As conversões CMYK das cores de ecrã são um ponto de partida — faça sempre uma prova antes de uma tiragem.
