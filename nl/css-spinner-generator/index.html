CSS-laadspinnergenerator — Ring, boog & stippen (pure CSS)

Kortom: de CSS-spinnergenerator bouwt pure-CSS laadanmaties — een klassieke ring, een gemaskerde conische boog of stuiterende stippen — met regelaars voor grootte, dikte, kleur en snelheid, en exporteert de volledige CSS inclusief keyframes.

Elke app heeft een laadstatus nodig, en GIF-spinners zijn zwaar en vaag. Deze drie spinners zijn elk een paar regels CSS: gewichtloos, scherp op elk formaat en met één waarde opnieuw gekleurd.

Privacy in het ontwerp: alles in deze tool gebeurt 100% in je browser met JavaScript. Je gegevens, foto’s en ontwerpen worden nooit naar een server geüpload, nooit opgeslagen en nooit door ons gezien - sluit het tabblad en alles is weg.

Hoe gebruik je de CSS-spinnergenerator

  1. Kies een stijl: Ring voor klassiek, Boog voor modern minimaal, Stippen voor vriendelijk.
  2. Stel grootte, dikte, kleur en snelheid in — het voorbeeld draait de echte animatie.
  3. Kopieer de CSS. Voor de stippenstijl is het HTML-fragment als commentaar in de uitvoer opgenomen.

Hoe het werkt

Ring- en boogspinners draaien een volledige cirkel met een keyframes-animatie; de boog gebruikt een conic-gradient die in een ring is gemaskeerd, zodat zijn staart geometrisch uitfadeert. Stippen gebruiken verspringende animatievertragingen op één stuiter-keyframe — de vertraging, niet afzonderlijke animaties, creëert de golf.

Uitgewerkt voorbeeld

Een toolsite vervangt haar GIF-lader door de blauwgroene ring van 54 px van hier — de pagina verliest 180 KB en de spinner past bij het merk.

Veelgestelde vragen

Welke spinner is het professioneelst?

De ring op matige snelheid (0.8–1s) is de bedrijfsstandaard. Stippen voelen vriendelijker; de boog voelt het modernst.

Respecteert het instellingen voor verminderde beweging?

Voeg een mediaquery toe in je CSS: @media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } } — vertragen in plaats van verwijderen behoudt de betekenis.

Mag ik de snelheid later veranderen?

Ja — één getal (de animatieduur) in de gekopieerde CSS.

Pure CSS — geen JavaScript?

Correct. Het voorbeeld gebruikt dezelfde CSS die de tool exporteert.
