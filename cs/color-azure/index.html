Azure — #F0FFFF

Stručně: Azure je #F0FFFF (RGB 240, 255, 255) — barva chladná a světlá, téměř bílá / pastelová, s úplným vypočteným profilem, škálou odstínů a harmoniemi.

Jedna z 148 pojmenovaných barev definovaných v CSS — tato stránka je jejím kompletním pracovním profilem: každý formát, kontrast WCAG, škála odstínů 50–950 a vypočtené harmonie, vše připravené ke kopírování.

Jak barvu Azure dobře používat

Azure patří do skupiny téměř bílá / pastelových barev při světlosti na úrovni 97% — barva světlá, živá a chladná. Jako pozadí se k ní nejlépe hodí text — černá (kontrast 20.45:1). Její doplňková barva (#FFF0F0) je energickým partnerem pro výzvy k akci a zvýraznění; analogické sousední barvy (#F0FFF8, #F0F8FF) dávají klidné přechody ze stejné rodiny. Pro tisk začněte od výše uvedených hodnot CMYK a proveďte nátisk — na obrazovce je Azure barva sRGB a syté tóny obrazovky se v tisku mohou posunout.

Časté dotazy

Jaký je hexadecimální kód barvy Azure?

#F0FFFF — pojmenovaná barva CSS „azure“. Její RGB je (240, 255, 255).

Hodí se Azure spíše pro text, nebo pro pozadí?

Jako pozadí: nejlepší čitelnost na něm má text — černá (20.45:1). Jako text samotný na pozadí — bílá dosahuje 1.03:1 — na běžný text podle AA to nestačí; používejte ji pro nadpisy, velký text nebo akcenty.

Jaké barvy se hodí k Azure?

Její doplňková barva #FFF0F0 pro kontrast, analogické #F0FFF8 a #F0F8FF pro klidné kombinace a výše uvedená škála odstínů 50–950 pro monochromatické návrhy.

Jaká je barva Azure v CMYK pro tisk?

C6 M0 Y0 K0. Převody barev obrazovky na CMYK jsou jen výchozí bod — před zahájením tisku vždy proveďte nátisk.
