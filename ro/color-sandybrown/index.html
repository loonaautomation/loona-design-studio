Cum folosești bine culoarea Sandybrown

Sandybrown face parte din familia culorilor portocaliilor, cu luminozitate de 67% — o culoare deschisă, vie și caldă. Pe acest fundal se citește cel mai bine textul negru (contrast 10.33:1). Culoarea ei complementară (#60B0F4) este un partener energic pentru îndemnuri la acțiune și accente; vecinii analogi (#F46066, #F4EE60) dau degradeuri calme din aceeași familie. Pentru tipar, pornește de la valorile CMYK de mai sus și fă o probă de tipar — pe ecran Sandybrown este o culoare sRGB, iar tonurile bogate de pe ecran se pot schimba la tipar.

Întrebări frecvente

Care este codul hexazecimal pentru Sandybrown?

#F4A460 — culoarea CSS cu numele „sandybrown”. RGB-ul ei este (244, 164, 96).

Este Sandybrown potrivită pentru text sau pentru fundaluri?

Ca fundal: textul negru se citește cel mai bine pe el (10.33:1). Ca text pe fundalul „alb” ajunge la 2.03:1 — insuficient pentru textul de bază la nivel AA; folosește-o pentru titluri, text mare sau accente.

Ce culori se potrivesc cu Sandybrown?

Complementara ei #60B0F4 pentru contrast, analoagele #F46066 și #F4EE60 pentru combinații calme și scala de nuanțe 50–950 de mai sus pentru designuri monocrome.

Care este Sandybrown în CMYK pentru tipar?

C0 M33 Y61 K4. Conversiile culorilor de ecran în CMYK sunt doar un punct de pornire — fă întotdeauna o probă înainte de tiraj.
