Sådan virker Loona Design Studio

  1. Vælg et værktøj og tilføj dit materiale. Skriv dine data, slip fotos ind, eller start fra en skabelon – alt læses kun af din egen browser.
  2. Design med live-forhåndsvisning. Layouts, farver, tekst og former opdateres med det samme på lærredet, mens du arbejder.
  3. Download den færdige fil. Skarpe PNG'er, trykklare størrelser, ZIP-pakker og kopiklar CSS - lavet på din enhed.

Hvorfor folk stoler på browserbaserede værktøjer

De fleste online designsteder beder dig uploade dine fotos, logoer og dokumenter til en fremmeds server - og beholde dem der. Loona Design Studio er bygget på den modsatte måde: designkoden kommer til dine filer, ikke omvendt. Det betyder hurtigere resultater, privatliv der virker overalt, og intet af dit gemt, logget eller delt. Luk fanen, og ethvert spor af dit arbejde er væk.

Loona Design Studio er en del af Loona Automations familie af gratis, problemløsende værktøjer. Spørgsmål eller forslag? E-mail os på loonaautomation@gmail.com.

Ofte stillede spørgsmål

Er Loona Design Studio-værktøjer virkelig gratis?

Ja – ethvert værktøj er 100 % gratis, uden tilmelding, uden vandmærker og uden daglige begrænsninger fra os.

Uploades mine fotos og designs nogen steder?

Aldrig. Hvert værktøj kører 100 % i din browser. Dine fotos, data og designs forbliver på din enhed fra start til slut - det er hele designet.

Hvilke enheder understøttes?

Enhver moderne browser på telefon, tablet eller computer - Chrome, Edge, Firefox og Safari virker alle. Tegne- og redigeringsværktøjerne understøtter berøring såvel som mus.

Virker værktøjerne offline?

Når en værktøjsside er indlæst, virker næsten alt, selv hvis din forbindelse ryger, fordi det hele sker lokalt på din enhed.

Hvor er Meme-generatoren og Farvepalettegeneratoren?

De bor i Loona Billedværktøjer, vores søsterwebsted – Meme-generatoren og Farvepalettegeneratoren er linket fra sidefoden, så intet nogensinde duplikeres på tværs af websteder. Dette websteds forløbsværktøj er multistop-versionen i CSS-udviklerkvalitet.
