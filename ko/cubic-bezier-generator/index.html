큐빅 베지에 이징 생성기 — 시각적 CSS 애니메이션 곡선

요컨대: 큐빅 베지어 생성기는 CSS 이징 곡선을 조각하게 해요 — 모든 전환과 애니메이션의 가속 느낌 — 네 개의 핸들, 유명한 프리셋, 그려진 곡선, 정확한 이징을 다시 재생하는 공과 함께요.

ease, ease-in, ease-out은 무한한 움직임 느낌 공간의 세 점일 뿐이에요. 이 도구는 전체 공간을 열어요: 인터페이스가 느껴져야 하는 방식으로 공이 움직일 때까지 곡선을 드래그하세요.

미리보기 공 — 값을 바꾸면 이징과 함께 다시 재생돼요.

설계부터 비공개: 이 도구의 모든 것은 JavaScript와 함께 브라우저에서 100% 일어나요. 데이터, 사진, 디자인은 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

큐빅 베지에 생성기 사용 방법

  1. 랜드마크(이즈, 백, 바운스-아웃)를 배우려면 가장 가까운 프리셋에서 시작하세요.
  2. 핸들을 조정하세요: 핸들 1은 움직임의 시작을, 핸들 2는 끝을 만들어요. 0–1을 벗어난 Y 값은 오버슈트(기대감과 반동)를 만들어요.
  3. cubic-bezier() 값을 전환이나 애니메이션에 복사하세요.

작동 방법

CSS 큐빅 베지에는 (0,0)에서 (1,1)로 가는 매개변수 곡선이며 제어점이 두 개예요. 브라우저는 이 페이지와 똑같이 풀어요: 주어진 시간 x에 대해 x가 일치하는 곡선 매개변수를 찾고(여기서는 이진 탐색), 그 y를 진행도로 읽어요. 오버슈트는 [0,1] 밖의 제어점 y 값에서 나와요.

실제 예

메뉴가 밋밋하게 밀려 들어오는 대신 기분 좋게 "톡" 튀어 나와요: 여기서 빌려온 back 프리셋의 오버슈트가 앱의 시그니처 움직임이 돼요.

자주 묻는 질문

네 개의 숫자는 무엇을 의미하나요?

제어점 두 개: (x1, y1, x2, y2)예요. x는 시간(0–1을 유지해야 해요), y는 진행(넘쳐도 자유로워요).

공이 "뒤로" 가면 왜 뒤로 가나요?

음의 y1은 진행이 시작부터 아래로 꺼지게 해요 — 던지기 전의 움츠림이죠. 그 기대감이 생동감을 만들어요.

UI 이징 — 좋은 기본값인가요?

ease-out 곡선(빠른 시작, 부드러운 착지)은 대부분의 인터페이스 움직임에 적합해요. ease-in은 화면을 떠나는 요소에 적합해요.

내 곡선이 유효한 CSS인가요?

네 — [0,1]의 모든 x가 작동해요. 생성기의 슬라이더가 정확히 그것을 강제해요.
