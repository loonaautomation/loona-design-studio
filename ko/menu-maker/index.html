메뉴판 만들기 — 무료 레스토랑 & 카페 메뉴

요컨대: 메뉴 메이커는 카페나 레스토랑 메뉴를 배치해요 — 제목, 섹션, 점선 리더와 가격이 있는 요리 이름 — 완전히 편집할 수 있는 인쇄 가능한 A4 캔버스에요.

메뉴는 주방보다 먼저 음식을 팔아요: 명확한 섹션, 정직한 가격, 숨 쉴 공간이에요. 템플릿에는 이미 고전적인 구조가 있어요. 당신은 요리만 가져오세요.

블록을 클릭해 선택하고, 드래그해 옮기고, 오른쪽 아래 모서리를 드래그해 크기를 조정하세요. 레이어: 뒤로 보내기 / 앞으로 가져오기를 쓰세요.

설계부터 비공개: 이 도구의 모든 것은 JavaScript와 함께 브라우저에서 100% 일어나요. 데이터, 사진, 디자인은 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

메뉴판 만들기 사용 방법

  1. 크기와 시작 템플릿을 고르세요 — 모든 템플릿은 완전히 편집할 수 있어요. 잠긴 것은 없어요.
  2. 아무 텍스트, 도형, 사진 블록이나 클릭해 편집하세요: 드래그해 옮기고, 모서리를 드래그해 크기를 조정하고, 캔버스 아래 편집기에서 스타일을 바꾸세요.
  3. 나만의 사진 블록과 배경을 추가하고, 뒤로 보내기 / 앞으로 가져오기로 레이어를 정리하세요.
  4. 선택한 정확한 크기로 PNG를 다운로드하거나, 종이 사본에는 인쇄 / PDF로 저장을 쓰세요.

작동 방법

메뉴 텍스트 블록은 요리와 가격 사이에 점 리더를 써요 — 고전적이고 읽기 쉬운 패턴이에요. 각 섹션을 하나의 텍스트 블록으로 편집하세요: 요리 이름 길이를 비슷하게 유지해 점을 정렬하거나, 자유롭게 다듬으세요 — 캔버스는 당신의 것이에요. 이 페이지는 Loona의 공유 캔버스 편집기로 실행돼요: 디자인은 선택한 정확한 픽셀 크기로 렌더링되는 텍스트, 도형, 사진 블록의 쌓임이라, 내보내기가 인쇄와 플랫폼에 바로 맞아요. 블록은 캔버스 안에 고정되고 레이어는 순서를 바꿀 수 있어요. 모든 작업은 브라우저에서 일어나요 — 사진은 업로드되지 않아요.

실제 예

한 작은 카페 주인이 손글씨 메뉴판을 이 인쇄된 A4 메뉴로 바꿔요. 가격이 드디어 잘 읽히고, 수정은 오 분이면 돼요.

자주 묻는 질문

가격은 어떻게 바꾸나요?

섹션의 텍스트 블록을 클릭하고 줄을 편집하세요 — 이름, 점, 가격은 일반 텍스트예요.

내 카페 사진이나 로고를 추가할 수 있나요?

네 — + 사진 블록 추가가 사진을 메뉴의 어디에든 배치해요.

어떤 크기가 가장 잘 인쇄되나요?

A4 — 라미네이트해서 탁상용으로 쓰거나, 벽 게시판용으로 큰 크기를 인쇄하세요.

무료인가요?

네 — 무료, 가입 없음, 워터마크 없음이에요.
