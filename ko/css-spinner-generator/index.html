CSS 로딩 스피너 생성기 — 링, 호 & 도트 (순수 CSS)

요컨대: CSS 스피너 생성기는 순수 CSS 로딩 애니메이션을 만들어요 — 고전적인 링, 마스크된 원뿔 호, 튀는 점 — 크기, 두께, 색상, 속도 컨트롤과 함께, 키프레임을 포함해 완전한 CSS를 내보내요.

모든 앱에는 로딩 상태가 필요하고, GIF 스피너는 무겁고 흐릿해요. 이 세 가지 스피너는 각각 몇 줄의 CSS예요: 무게가 없고, 모든 크기에서 선명하고, 값 하나로 색상을 바꿀 수 있어요.

설계부터 비공개: 이 도구의 모든 것은 JavaScript와 함께 브라우저에서 100% 일어나요. 데이터, 사진, 디자인은 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

CSS 스피너 생성기 사용 방법

  1. 스타일을 선택하세요: 고전적인 링, 현대적 미니멀한 호, 친근한 도트예요.
  2. 크기, 두께, 색상, 속도를 설정하세요 — 미리보기가 실제 애니메이션을 실행해요.
  3. CSS를 복사하세요. 도트 스타일에는 HTML 스니펫이 출력에 주석으로 포함되어 있어요.

작동 방법

링과 호 스피너는 키프레임 애니메이션으로 원 전체를 회전해요. 호는 원뿔 그라데이션을 링으로 마스크해 꼬리가 기하학적으로 사라져요. 점은 하나의 바운스 키프레임에 시차를 둔 애니메이션 지연을 써요 — 별도의 애니메이션이 아니라 지연이 물결을 만들어요.

실제 예

한 도구 사이트가 GIF 로더를 여기서 가져온 54 px 틸 링으로 바꿔요 — 페이지가 180 KB 가벼워지고 스피너가 브랜드와 맞아요.

자주 묻는 질문

어떤 스피너가 가장 전문적인가요?

적당한 속도의 링(0.8–1초)은 기업 표준이에요. 점은 더 친근하게 느껴지고, 호는 가장 현대적으로 느껴져요.

움직임 감소 설정을 존중하나요?

CSS에 미디어 쿼리를 추가하세요: @media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } } — 제거가 아니라 늦추는 것이 의미를 지켜요.

나중에 속도를 바꿀 수 있나요?

네 — 복사한 CSS의 숫자 하나(애니메이션 지속 시간)예요.

순수 CSS — JavaScript가 없나요?

맞아요. 미리보기는 도구가 내보내는 것과 같은 CSS를 써요.
