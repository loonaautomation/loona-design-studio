이미지 주석 편집기 — 스크린샷에 화살표, 라벨 & 개인정보 블러 추가

요컨대: 이미지 주석 편집기는 튜토리얼과 버그 보고서가 필요한 방식으로 스크린샷과 이미지를 마크업해요: 굵은 화살표, 강조 상자, 텍스트 라벨 — 그리고 공유하기 전에 이름, 번호, 얼굴을 픽셀화하는 개인정보 흐림이에요. 내보내기는 이미지의 전체 원본 해상도로 렌더링돼요.

이것은 사진 편집기가 아니에요 — 여기에는 필터나 뷰티 도구가 없어요(Loona Image Tools가 사진 편집을 담당해요). 이 도구는 일이 하나예요: 설명하고 보호하는 것이에요. 버튼을 가리키고, 단계에 라벨을 붙이고, 계정 번호를 흐리게 하고, 노출 없이 가르치는 스크린샷을 공유하세요.

설계부터 비공개: 이 도구의 모든 것은 JavaScript와 함께 브라우저에서 100% 일어나요. 데이터, 사진, 디자인은 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

이미지 주석 편집기 사용 방법

  1. 설명하고 싶은 스크린샷이나 이미지를 업로드하세요. 그것은 브라우저로만 로드돼요.
  2. 화살표를 선택하고 눈이 시작해야 할 곳에서 가리키는 대상까지 드래그하세요. 상자로 영역을 프레임하고, 텍스트 라벨(먼저 텍스트를 입력한 뒤 클릭해 배치)을 쓰세요.
  3. 개인정보 블러를 선택하고 민감한 것 — 이름, 전화번호, 계정 정보, 얼굴 — 위를 드래그하세요. 영역이 픽셀화되어 읽을 수 없어요.
  4. 실행 취소는 마지막 표시를 제거해요. 다운로드는 모든 표시가 구워진 전체 해상도 PNG를 내보내요.

작동 방법

표시는 표시된 이미지에 대한 상대 좌표로 저장되고, 내보내기 위해 이미지의 자연 해상도로 다시 렌더링돼요 — 그래서 화살표와 라벨은 큰 스크린샷에서도 선명하게 유지돼요. 블러는 원본 이미지 영역을 샘플링하고, 몇 개 픽셀로 줄이고, 부드럽게 처리를 끈 채 다시 늘려요. 세부 사항을 가리는 것이 아니라 파괴하는 거예요. 모든 것이 로컬에서 실행돼요. 이미지는 기기를 절대 떠나지 않아요.

실제 예

사용법을 안내하는 가이드를 준비하면서, 한 교사가 학교 포털을 스크린샷으로 찍고, "제출" 버튼에 빨간 화살표를 그리고, "1 — 제출 클릭"이라고 라벨을 붙이고, 학생 ID 열을 흐리게 한 뒤, 모든 부모에게 보내기 안전한 가이드 이미지를 내보내요.

자주 묻는 질문

Loona Image Tools와 어떻게 다른가요?

Image Tools는 사진을 편집해요 — 크기 조정, 압축, 필터, 워터마크예요. 이 편집기는 설명을 위해 스크린샷에 주석을 답니다: 화살표, 상자, 라벨, 개인정보 블러예요. 다른 일, 다른 도구예요.

블러가 정말로 정보를 숨기나요?

네 — 영역은 거친 블록 크기에서 원본 픽셀에서 픽셀화돼요. 그래서 밑에 있는 텍스트나 얼굴은 내보내기에서 파괴돼요. 그냥 덮이는 것이 아니에요. 공유하기 전에 항상 내보낸 이미지를 확인하세요.

내보내기가 흐릿해지나요?

아니에요 — 표시는 이미지의 전체 원본 해상도로 다시 렌더링돼요. 그래서 내보내기가 원본 스크린샷만큼 선명해요.

표시를 배치한 뒤에 옮길 수 있나요?

실행 취소를 써서 마지막 표시를 제거하고 다시 배치하세요 — 표시는 순서대로 유지돼요. 그래서 실행 취소는 한 번에 한 단계씩 돌아가요.

내 스크린샷이 어딘가에 업로드되나요?

절대 아니에요. 이미지와 표시는 브라우저에만 존재해요.
