Генератор на CSS спинери за зареждане — Пръстен, дъга и точки (чист CSS)

Накратко: генераторът на CSS спинери изгражда анимации за зареждане от чист CSS — класически пръстен, маскирана конична дъга или подскачащи точки — с контроли за размер, дебелина, цвят и скорост и експортира пълния CSS, включително keyframes.

Всяко приложение се нуждае от състояние на зареждане, а GIF спинерите са тежки и размазани. Тези три спинера са по няколко реда CSS всеки: безтегловни, остри при всеки размер и преоцветявани с една стойност.

Поверително по дизайн: всичко в този инструмент се случва 100% във вашия браузър с JavaScript. Вашите данни, снимки и дизайни никога не се качват на сървър, никога не се съхраняват и никога не се виждат от нас — затворете раздела и всичко изчезва.

Как да използвате Генератор на CSS спинери

  1. Изберете стил: Пръстен за класически, Дъга за съвременен минимален, Точки за приятелски.
  2. Задайте размер, дебелина, цвят и скорост — прегледът пуска истинската анимация.
  3. Копирайте CSS. За стила с точки HTML фрагментът е включен като коментар в изхода.

Как работи

Спинерите пръстен и дъга завъртат пълен кръг с анимация на ключови кадри; дъгата използва conic-gradient, маскиран в пръстен, така че опашката ѝ избледнява геометрично. Точките използват разминати закъснения на анимацията върху един ключов кадър за подскачане — закъснението, а не отделни анимации, създава вълната.

Работен пример

Сайт с инструменти заменя своя GIF зареждащ елемент с тюркоазения пръстен от 54 px от тук — страницата губи 180 KB, а спинърът съответства на марката.

Често задавани въпроси

Кой спинер е най-професионален?

Пръстенът при умерена скорост (0.8–1s) е корпоративният стандарт. Точките се усещат по-приятелски; дъгата се усеща най-модерно.

Ще спазва ли настройките за намалено движение?

Добавете медийна заявка в CSS: @media (prefers-reduced-motion: reduce) { .loader { animation-duration: 2.4s; } } — забавянето, а не премахването, запазва смисъла.

Мога ли да променя скоростта по-късно?

Да — едно число (продължителността на анимацията) в копирания CSS.

Чист CSS — без JavaScript?

Вярно. Прегледът използва същия CSS, който инструментът експортира.
